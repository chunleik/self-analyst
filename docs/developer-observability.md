# 开发者 Langfuse 观测

此功能用于调试，不是 MCP 连接，也不是新的模型服务。入口为**配置 → 开发者功能 → Langfuse 观测**。默认关闭、默认元数据模式。显示页面、保存配置、保存密钥均不启用上传；启用及合成连接测试有各自的确认。

## 配置步骤

1. 在你管理的 Langfuse 项目中取得 Public Key 和 Secret Key。填入 Java 后端实际能够访问的服务器地址，可为服务根地址或含反向代理前缀的完整 OTLP traces 地址。应用规范化为 `/api/public/otel/v1/traces`，启用确认以保存后的完整地址和项目为准。
2. 本机服务可使用 `http://127.0.0.1:3000`、`http://[::1]:3000` 或解析为回环的 `http://localhost:3000`。**本机指运行 SelfAnalyst Java 后端的机器**，不是任意查看页面的电脑。LAN/公网服务器必须 HTTPS，证书链、主机名和有效期须正确。可填写仅作用于观测连接的 CA 证书 PEM；不接受私钥、不跳过校验、不改操作系统信任。
3. 保存配置，再单独保存 Secret Key。当前持久秘密存储使用 Windows 当前用户系统凭据库，配置文件只保存引用。其他平台或凭据库不可用时明确失败，不以普通 JSON、TOML 或浏览器存储代替加密存储。保存后不回显密钥。
4. 可选择**合成连接测试**，仅发送固定非业务 span，不调用模型或读取邮件。接收成功不等于已在 Langfuse 页面索引，请另查你的实例版本、项目和处理队列。
5. 选择模式、范围和来源，保存后单独确认启用。启用/测试前先进行不携带密钥的 DNS 预览，确认中显示接收地址、项目、解析 IP 集合、证书信任指纹、类别与来源；确认 token 短期有效，取消不发送 trace。启用仅持续本次应用运行，重启后重新确认；不会单独扫描、补传历史聊天；但后续合法模型调用本身可能携带先前会话上下文，已选内容范围也适用于这些上下文。配置或密钥变化会停止旧授权，必须重新启用。

协议为 OpenTelemetry Java SDK + 有界 OTLP HTTP/JSON 导出，Basic 项目认证与 `x-langfuse-ingestion-version: 4`。客户实例须支持此 profile；不自动回退旧 ingestion 或 gRPC。拒绝嵌入账户的 URL、query/fragment、模糊路径、危险 IP、重定向和隐式系统代理。每次连接重新核对 DNS 并连接已验证的 IP，TLS 仍验证原主机；LAN 地址集合变化需重新启用。**这些规则不会放宽 MCP 的公网 HTTPS 限制。**

## 数据范围

- **元数据**：固定操作类别、随机关联 ID、运行版本、时序、结束状态和有来源标记的 token 用量。不发送聊天、标题、工具参数/结果/目录、邮件、图片、账户、路径或异常原文。Token 估算不是实际用量，ChatGPT 订阅也不据此计算真实账单。
- **模型文本**：单独选中后，仅在授权会话或本次运行范围内考虑实际模型调用的输入、输出、摘要/压缩文本。失败、取消或被权限守卫拒绝的模型调用不导出输入/输出。
- **工具文本/目录**：分别选择类别及具体 MCP 连接，选择一条连接覆盖其工具，不等于给该 MCP 额外调用批准。查看弹窗、发现工具及批准执行是独立操作；手动工具发现不归属单一聊天，需要选择本次运行范围才导出目录。原生工具和无法可靠判定来源的内容保守省略。
- **邮件**：额外选择明确账户和邮件头/正文类别。账户/目录/列表/搜索属于邮件头类别，读取正文及无法拆分的邮件衍生模型/压缩文本要求同时授权邮件头与正文。已在模型或摘要中混合的邮件来源也要满足相应类别和账户授权；来源不明则整段降级为元数据。模型接收方授权不是 Langfuse 授权，邮箱读取权限也不变。
- **图片、附件和二进制**：首期不上传内容，包括 data URL/base64。含图片或来源不明的衍生文本也可能整段省略，不能用文本选项绕过。

恢复的旧会话、原生工具结果或后台任务可能没有可靠的来源记录。它们仍可产生元数据，但即使选择内容模式，也可能不含内容。这是安全降级，不表示没有发生调用。不会为观测额外读取被模型过滤的事件、文件、邮箱或图片。

应用结构化认证字段、已知观测密钥、私钥及原始异常不导出；对用户自由文本的检测并不保证发现所有秘密。不要把“开发者模式”或自动屏蔽当成无限分享许可。确认前应检查数据是否适合交给你配置的服务及其管理员。

## 停止、删除与故障

- **停用**停止后续导出并清理未发送的内存队列；**断开并清理凭据**另外删除本地 Secret Key 引用。失败或清理待处理会显示，不能视为服务端 key 已撤销。待清理引用仅在当前进程重试，异常退出或重启不保证自动找回孤立保险库条目；必要时在 Windows 凭据管理器核实清理，并在服务端撤销 key。
- 更改地址、项目、证书或内容范围会撤销旧运行授权，旧排队内容不会转交新目标。MCP/邮箱源定义或凭据改变、删除或重新导入也会撤销内容授权及预览；同 ID 不代表同一账户，原会话的来源会保守标为未知，重新授权不把旧历史重标为新源。已经到达服务器的数据无法由停用撤回。
- 队列、批量、内容大小、超时及重试有上限。接收端离线、限流或拒绝不会阻塞聊天；页面显示接受、丢弃和失败计数。没有磁盘发送队列或历史补传。
- 配置损坏或安全存储不可用时观测关闭，保留原文件，不影响正常聊天；不得通过覆盖文件来猜测恢复。版本冲突需重载；写入结果未知时先停止观测并重新读取状态，不盲目重复写入。
- 删除 MCP 连接只清除本地连接、批准与该连接凭据，**不会删除 Langfuse trace、聊天、服务端日志、对象存储或备份**。接收方管理员、保留策略、密钥撤销及删除应在 Langfuse 管理。客户端内存排队不等于全系统绝不落盘或零留痕。

## 开发验证

自动测试使用合成模型、MCP 与 OTLP 接收端，不需要真实邮箱或生产项目密钥。实际客户 Langfuse 版本、页面索引、真实 QQ/163、Windows/Tauri 人工视觉验收是独立验收，不由单元测试或接收状态代替。
