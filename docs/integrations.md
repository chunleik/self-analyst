# MCP 连接与工具

本指南描述 `add-mcp-tool-management` 开发变更；已发布的 beta.19 仍以“连接与工具”和只读邮箱为准。
在受管桌面应用中打开顶部 **MCP**，配置本地邮箱和远端连接；设置仍默认进入“模型设置”。旧的无 token
本机访问模式不能管理连接、凭据或批准操作。配置连接给 SelfAnalyst 使用，与向其它本机客户端共享邮箱是两项独立操作。

## 配置与启用

连接配置保存在当前数据根的 `config/integrations.json`，格式版本为 1。`mcpServers`、`mailAccounts` 和工具批准记录采用独立 JSON，不向平面 TOML 塞入数组对象。普通 `config.toml` 保存不会覆盖它。

1. 添加连接或邮箱，保存公共元数据。默认禁用。
2. 外部 MCP 的 Bearer 默认仅本次进程有效，可显式选择系统库保存；邮箱授权码通过“加密保存并启用邮箱”确认操作存入系统安全存储。提交后输入框清空。
3. 点击测试或发现工具。测试不代表启用，也不自动批准工具；邮箱测试不读取正文。
4. 外部 MCP 对照远端工具描述和参数结构逐项批准，再显式启用；邮箱则在专用操作中核对读取范围、正文、模型目标及留存后确认。连接变更在下一轮聊天发布工具；撤权立即影响未执行的旧轮次调用。

保存本身不联网。运行启动和下一轮聊天为已启用连接安排异步发现，不等待全部远端服务器后才启动应用。离线、认证不足或发现失败的连接会显示状态，不阻断本地工具。修改无关设置不清空仍有效的目录。重启会重新建立已启用连接，但仅会话凭据需要重新输入。

保存使用 revision 乐观并发控制。冲突时先刷新，不能用迟到响应覆盖新编辑。写入使用同目录临时文件、强制刷新和原子替换；失败保留原配置。`.integrations.lock` 协调写入，`integrations.json.bak` 是前一版公共元数据，不含秘密。

## 删除连接与查看接口

选择连接后可点击“删除连接”。未保存的新连接只移除这一条内存草稿；已保存连接会先显示保存的名称、目标和影响，确认后按版本单独删除连接、关联工具批准并尝试清理本地凭据。其它连接及其未保存编辑保留，不需要为了删除空草稿先保存整页。取消不改变数据；版本冲突保留草稿。请求结果不明时暂时锁定写入，请确认放弃草稿并重新读取保存状态，不要连续重试。

“断开”仍只停用并清理凭据，保留条目；“删除连接”才移除条目。操作系统拒绝清理凭据时会显示待清理，不代表秘密已删除；必要时只处理能明确对应的 Windows 凭据管理器项目。删除不删除聊天或远端数据，不会在服务商处作废令牌。“放弃更改”丢弃整个连接页的未保存修改，不删除已保存连接。

MCP 的“查看 MCP 接口”打开只读弹窗，显示该连接已发现的 **tools** 名称、描述、输入参数 JSON Schema 和定义批准状态，并不枚举 MCP resources 或 prompts。打开不会联网；用户点击“发现工具/刷新工具列表”才通过现有发现接口读取目录。未保存元数据时先保存或放弃更改再发现；旧目标的目录不冒充新目标能力。尚未发现与已发现但无工具会分别说明，缓存目录不是远端实时保证。

查看、发现不自动批准、启用或执行工具。批准仍在连接设置中逐项进行，业务调用仍需单次确认。弹窗支持 Escape、关闭后焦点返回和窄屏滚动，第三方内容仅作为文本展示。

## 远端 MCP

已有的 Streamable HTTP 连接支持匿名或 Bearer。网络型连接仅允许 HTTPS 公网目标，不接受 URL 内账号、查询参数、片段、内网、回环、链路本地、元数据地址或非全球单播地址。每次交换重新检查全部 DNS 地址并连接已检查的地址，TLS 按原始主机名验证，不跟随重定向，也不使用进程代理。

已有实现复用 MCP SDK 的初始化、工具发现和调用，使用受限 HTTPS transport。Streamable HTTP 的响应可以是 JSON 或有限 SSE 事件流；这与独立的旧版 HTTP+SSE transport 不同。旧版 HTTPS SSE 只连接已验证的同源消息路径，流有界且不续传。stdio 使用本机绝对可执行文件路径和参数数组；保存与导入不执行，保存为停用后显式启用并核对命令，再手动测试或发现才执行。重启后须手动重新启动；不会继承秘密环境变量。这不是操作系统沙箱。OAuth、无限后台订阅和自动续传不支持。初始化、每次请求、响应体、工具数量、结构大小均有上限；不确定是否执行的调用不会自动重试。

远端工具使用本地命名空间，不能覆盖原生工具。工具描述和参数 schema 的摘要变化后，原批准不再有效。即使远端标记为只读，每次调用仍需要聊天中的真实确认卡。确认绑定会话、轮次、目标、配置版本、工具定义和精确参数；拒绝、超时、关闭、参数变化或撤权后不会执行。来自邮件、网页或模型文字的“同意”不能代替确认卡。

旧 `websearch.*` 键和 `WEBSEARCH_*` 环境变量已在本变更中退役。旧 TOML 原文可保留，不会生效、联网或迁移地址、凭据和工具批准。要继续搜索，请在 MCP 页面添加 **Parallel Search** 预设或明确配置其它公网 HTTPS 搜索端点，配置所需认证，发现并重新批准工具。选择预设只填公共地址和协议，不自动启用或联网。

## 凭据

外部 MCP 默认 `session` 只放在内存，用户显式选择持久保存时使用 Windows 当前用户的 Credential Manager。邮箱新凭据不再提供存储勾选项：在明确确认“加密保存并启用邮箱”后，强制使用该系统安全存储并回读核验；其它平台或系统库不可用时明确失败，不回退为仅会话或明文文件。目录发现可使用本次临时授权码，但不持久保存或启用；邮箱不提供旧会话凭据迁移。凭据绑定连接 ID 及精确目标；邮箱还绑定服务商与完整地址。改目标会清除旧引用和批准，不能把旧 Bearer 发给新服务器。

元数据保存、凭据替换和删除分开处理。替换先创建新引用，再提交配置，成功后删除旧项；提交失败尝试清理新项并保留旧项。退出清理会话凭据，持久凭据保留供下次使用。断开使本地连接不可用并尝试删除本地凭据；操作系统拒绝清理时会显示待清理提示，并在后续凭据操作或退出时重试。进程退出/崩溃后若保险库仍有孤立项，需要在 Windows 凭据管理器手工清理；不承诺系统拒绝删除时已擦除。远端授权码必须到服务商网站手工作废。

邮箱启用提交报错时，先核对持久配置，只有确认未提交才清理新凭据；若确认已提交则按真实成功结果返回。响应丢失、格式异常或无法核对时显示结果不确定并保留可能有效的凭据，不自动重试；使用“刷新状态”取得完整当前状态后再操作，关闭重开设置不跳过核对。保留可能有效的凭据不等于确认存在可删除的孤立项。

操作系统保险库不是同一登录用户下恶意进程的隔离边界。授权码可能具有比 SelfAnalyst 更大的权限，软件只读不表示服务商签发了只读授权码。日志不记录授权码、Bearer、邮箱正文或远端原始错误；MCP SDK 会输出原始内容的日志被关闭，仅显示本地分类状态。

## 邮箱与模型授权

内置邮箱连接器默认仅供 SelfAnalyst 进程使用。普通 QQ 和 163 为现有预设；普通 126 和使用应用专用密码的个人 Gmail 是新增固定预设。未验证个人真实邮箱。不支持 Exchange Online、自定义服务器或其它企业邮箱；需要各自的 OAuth 或连接信任审查。读取经服务商固定 IMAPS 端点，正文许可独立。可按下节单独启用本机 MCP 访问，或选择允许申请保存远端草稿和发信。详情见 [邮箱指南](mail-integration.md)。

新邮箱固定使用“全部文件夹”，覆盖服务商 IMAP 暴露的当前及以后新增的可读目录，包括嵌套目录。配置不自动加载目录；不启用账户、不授予正文读取或模型处理，也不触发后台同步。旧指定范围不会自动扩张，新表单不编辑指定范围。

邮箱表单保留正文选择与“断开”。普通保存不能启用账户；显式启用操作展示账户、范围、正文、当前模型目标及聊天保留说明，取消不提交，配置版本或展示目标过期时失败。改动服务商、地址、范围或正文权限后会先停用并要求重新确认；单独改显示名不影响启用。已有匹配的持久凭据可复用，启用成功不等于连接测试成功。

首次让某个会话中的邮箱数据进入模型前，会显示模型接收目标及聊天保留说明。更换接收地址后必须重新确认，原来的目标授权不能替代新目标授权；同一目标的密钥轮换不产生新接收方。聊天、压缩、列表摘要和修复会话的模型路径都检查实际租约目标；HTTP 重定向不会把数据转交其它目标。

邮箱来源标记由服务端在结果暴露前持久保存，不能通过模型参数或前端会话编辑清除。该会话停止自动长期记忆提炼，禁止会把邮件衍生查询发给 embedding 的语义搜索；只允许明确列出的本地只读工具，设置/记忆写入必须单次确认，其它原生工具默认拒绝。

## 向本机 MCP 客户端共享邮箱

1. 在 SelfAnalyst 中启用使用受支持预设的目标邮箱。进入顶部 **MCP → 本机 MCP 客户端接入**，逐个开启“允许本机 MCP 客户端访问此邮箱”，核对披露后保存。所有账户默认关闭；开启会将符合现有目录及正文许可的内容交给另一个应用，它可能自行记录或转发结果。不要为未经信任的客户端开放。
2. 点击“生成令牌”并立即“复制客户端配置”。托管端专用令牌存入当前 Windows 用户的 Credential Manager；不能用桌面认证令牌、IMAP 授权码或 SMTP 授权码代替。系统凭据库不可用时不会回退。复制内容包含秘密，不要放入仓库、日志或聊天。令牌刷新后旧值立即失效；需要更新使用它的客户端配置。
3. 在同一台电脑上配置支持 Streamable HTTP 和自定义 `Authorization: Bearer …` 的客户端。地址为页面显示的 `http://127.0.0.1:<端口>/mcp/all`（全部已开放的邮箱）或 `/mcp/<账户 ID>`（一个已开放的邮箱）。若端口未固定，重启后核对地址。一个令牌可以访问所有已开放邮箱，并非每个账户各有令牌；单账户 URL 不限制持有该令牌的客户端访问其它已开放账户。
4. 要开放写操作，再独立开启“允许申请保存草稿”或“允许申请发送邮件”。发信还需先单独保存该账户的 SMTP 授权码到 Windows 凭据库；保存授权码不自动开启发信。每次写入都要在受管桌面核对发件账户、收件人、主题和完整正文并批准；本机客户端的请求在 MCP 页的“邮箱写操作请求”显示。关闭权限、轮换令牌或修改账户后不能沿用旧批准。

本机入口只绑定回环，复用已有后端监听端口，支持 Streamable HTTP JSON 工具调用，不暴露第三方 MCP、resources 或 prompts，不作为局域网/公网服务。请勿将其反代或转发到远程设备；云端客户端不能直接访问这台电脑的 `127.0.0.1`，未验证指定客户端（含 Claude 云端）的兼容性。两个地址都仅返回显式开放邮箱；没有符合条件的账户时不提供工具服务。

## 导入、备份与回退

`GET /desktop/integrations/export` 仅导出公共元数据，不包含本机 MCP 共享规则、客户端令牌或 SMTP 授权码。导入清除连接的机器凭据引用、启用状态、工具批准和邮箱披露确认；不会启动子进程，未知传输/字段被拒绝。备份 JSON 不会备份保险库秘密。新机器恢复后，配置存在不代表已认证。

邮箱范围通过 `folderScope` 的 `all` / `selected` 明确表达，`allowedFolders` 仅在指定模式下决定精确白名单。邮箱必须有明确范围，缺少字段会报错而不猜测或迁移；非法配置不会被静默覆盖。新配置保存和导出会写出该字段，导入保留范围含义但不会继承启用和披露授权。旧版本的严格解析器不支持新字段，会拒绝读取；降级前保留备份，不应删除范围字段来模拟安全降级。

数据根准入在建立连接/凭据前检查格式。新增邮箱来源表使用独立版本标记，旧会话数据继续兼容；恢复后来源标记与目标授权随会话数据库保留。降级前保留完整停机备份，旧版本没有本期权限和来源保护，不能将降级视为安全兼容路径；不要手工删除标记或降低格式版本。

删除会话与断开账户不同：会话历史、AgentState 和来源记录按现有删除协调清理，备份、用户另存文件、远端邮箱及模型已收数据不会因此撤回。不存在“正文零落盘”保证。

## 验证范围

自动化使用合成凭据、MCP 响应、IMAP/SMTP TLS 服务器和 MIME 消息。本变更的真实邮箱账户、Windows 系统凭据库、打包桌面端和实机 MCP 客户端验收不由合成测试替代；校验通过项和未运行项以变更的验证记录为准。
