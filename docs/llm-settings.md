# 模型设置指南

点击桌面右上角配置按钮，默认进入“模型设置”。本功能管理一个 OpenAI-compatible 连接，
供聊天、摘要和现有 Agent 运行时使用；当前不提供多 Provider 保存、原生 Anthropic/Gemini 协议或模型路由。

## 配置与验证

1. 选择 OpenAI、DeepSeek、OpenRouter 预设，或填写自定义 HTTP(S) Base URL。
2. 输入目标服务 API Key。已有密钥不回显；留空保留当前密钥及来源关系。
3. 点击“加载模型列表”取得候选 ID，或直接输入模型名称。目录不可用时仍可手工填写。
4. 设置温度和单次输出上限。温度范围为 0–2；输出上限为非负整数，0 表示不发送上限参数，供应商仍有自身限制。
5. 可选“测试生成连接”：发送固定的最小请求，可能产生少量计费。测试不携带会话或采集数据，且不保存配置。
6. 点击“保存并应用”。查看运行状态：新工作生效、旧工作仍在执行、未配置，或其它组件需重启。

目录包含的模型不一定支持聊天。测试通过只证明当前草稿能完成该最小生成请求，不保证全部工具调用
或后续长对话成功。部分模型不支持最小测试参数时会报告参数错误；保存不依赖测试成功。

## 凭据及配置来源

| 操作 | 保存后的含义 |
|---|---|
| 密码框留空 | 保留已有密钥覆盖与继承关系 |
| 输入新密钥 | 替换用户密钥覆盖 |
| 清空密钥 | 写入显式空值，阻止环境变量兜底，新模型工作不可用 |
| 恢复密钥继承 | 删除用户覆盖，恢复 `OPENAI_API_KEY` 等既有解析规则 |
| 非敏感字段恢复继承 | 删除该字段的用户覆盖，采用环境变量或默认值 |

清空和恢复密钥继承分别确认，选中操作只修改草稿，保存后才生效。修改地址后使用旧密钥测试会被拒绝，
需要重新输入目标服务密钥。查询、错误和日志不返回密钥；输入不进入浏览器持久存储。
密钥仍按现有配置方式存放于 TOML，并非系统凭据库；已认证用户可以在高级配置中查看原文。

## 保存与高级配置

模型表单只更新实际修改的五个 LLM 字段，保留无关配置、未知合法键、中文注释、空行和换行风格。
目标是复杂多行语法或无法安全插入时，保存会拒绝并保留原文，请改用“高级配置”。该限制不影响
原文 API 对合法 TOML 的既有支持。旧通用结构化端点和 Agent 工具仍不承诺注释保真。

保存复用既有提交协调与运行租约。失败时旧文件及运行版本保持不变；正在执行的回答继续使用原模型。
Embedding 继承密钥变化仍需单独重启，不会自动启用原本禁用的功能。同进程写入串行处理，只提交指定
字段；多个窗口同时修改同一字段时后提交者生效，不提供跨进程冲突事务。

模型设置与高级配置切换时如有未保存草稿，会询问是否放弃；取消则保留草稿，确认则读取目标视图的最新
已保存内容。需要保存草稿时先取消切换并保存。高级配置保留原文逐字保存、配置键定位、语言设置及
Embedding 检查；旧 LLM 按钮标明为目录连接检查。

## 开发验证

`node scripts/llm-settings-preview.mjs` 启动仅监听本地回环的内存假数据预览服务，控制台输出临时 URL。
该服务用于检查页面布局及交互，不读写真实配置、不访问供应商；结束后按 Ctrl+C 关闭。
后端测试用本地 HTTP fixture 验证真实接口及运行切换，自动化测试不使用付费请求。

预设地址参考：[OpenAI 模型 API](https://developers.openai.com/api/reference/resources/models/methods/list)、
[DeepSeek OpenAI-compatible 地址](https://api-docs.deepseek.com/quick_start/agent_integrations/nanobot/)、[OpenRouter API](https://openrouter.ai/docs/api_reference/overview)。
预设只辅助填写地址，不维护模型能力和价格目录；供应商协议变化时应重新核对文档。
