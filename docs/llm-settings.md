# 模型设置指南

点击桌面右上角配置按钮，默认进入“模型设置”。可选择 **API Key** 或 **ChatGPT 登录**，
供聊天、摘要和现有 Agent 运行时使用。同一时间只有一个活动连接；可以保留一个 API Key 连接及多个
ChatGPT 账户，切换时不会删除另一种方式的凭据。不提供自动供应商回退、原生 Anthropic/Gemini 协议或模型路由。

## API Key：配置与验证

1. 选择“API Key”，再选择 OpenAI、DeepSeek、OpenRouter 预设，或填写自定义 HTTP(S) Base URL。
2. 输入目标服务 API Key。已有密钥不回显；留空保留当前密钥及来源关系。
3. 点击“加载模型列表”取得候选 ID，或直接输入模型名称。目录不可用时仍可手工填写。
4. 设置温度，范围为 0–2。应用不发送输出上限参数，实际输出限制由模型服务端决定。
5. 可选“测试生成连接”：发送固定短提示，不设置输出上限，用量和计费由模型服务端决定。测试不携带会话或采集数据，且不保存配置，仍有超时与响应大小限制。
6. 点击“保存并应用”。查看运行状态：新工作生效、旧工作仍在执行、未配置，或其它组件需重启。

目录包含的模型不一定支持聊天。测试通过只证明当前草稿能完成该短提示生成请求，不保证全部工具调用
或后续长对话成功；保存不依赖测试成功。测试最多等待 15 秒，响应最多读取 1 MiB，不跟随携带凭据的重定向。

## ChatGPT 登录：资格与授权

此连接使用 OpenAI 的 **Sign in with ChatGPT 开源客户端预览**。服务端必须向你的账户开放动态客户端注册、
直接模型访问和相应模型权限。**拥有 ChatGPT 订阅不代表拥有 OpenAI API 额度，也不保证此预览可用。**
可用套餐、地区、模型、配额及服务条款由 OpenAI 决定；本应用不承诺免费或无限调用，也不从订阅名称推断权限。

1. 选择“ChatGPT 登录”，点击“添加账户”。桌面版通过系统浏览器打开 OpenAI 授权页面；如未打开，
   点击“打开 OpenAI 登录页面”重试。只在 OpenAI 页面登录，不向 SelfAnalyst 提交密码或手工粘贴令牌。
2. 核对授权对象为 SelfAnalyst，并审阅身份、离线刷新和直接模型访问权限。授权使用 PKCE 和本机回环回调，
   每次尝试有效期为 5 分钟。取消登录或关闭设置会取消未完成的尝试；过期后需要重新发起。
3. 授权后返回设置，刚登录的账户会选入草稿。可添加多个账户，或选择已有账户并“重新登录”。
   **登录成功只说明授权完成，不代表所选模型已能生成，也不会自动保存活动连接。**
4. 点击“加载模型列表”，从账户目录选择模型，或手工输入服务端支持的模型 ID。ChatGPT 模型没有固定默认值；
   不会沿用 API Key 的模型。目录只展示服务端允许列出的条目，不是完整模型承诺；目录不可用时仍可手工填写。
5. 可选“测试生成连接”：仅发送固定短提示 `Reply OK.`，不携带会话、活动标题、文件元数据或工具上下文。
   测试会使用服务端分配的额度，最长等待 45 秒。有效生成结果才算通过；一次短测试不保证长对话、图片或工具均可用。
6. 点击“保存并应用”，让新工作使用所选账户和模型。测试和登录都不代替保存；账户、模型和本地运行状态
   不代表服务端仍有可用额度。已启用的摘要等模型工作也会使用这个活动连接。

ChatGPT 使用固定的 OpenAI Responses 接口，不使用 API Key 表单中的 Base URL、模型或温度。
图片、工具调用及上下文容量仍受所选模型和预览协议限制，不能把 ChatGPT 网页中的全部功能视为本应用能力。
客户端不自动重试一次生成，也不会因权限、限流或网络失败自动改用其它账户或 API Key。

授权未授予直接模型访问权限时，账户注册仍可保留，界面会提示权限不足。检查账户资格后重新登录并授权，
或主动切换回 API Key。遇到限流或用量耗尽时，该账户在本次应用进程中的后续模型调用会暂停；
等待服务端额度恢复后，主动运行成功的生成测试可恢复调用。应用的本地 token 统计不是 OpenAI 剩余订阅额度查询。

点击“断开账户”并确认，会清除所选账户的本地 OAuth 令牌，并尝试撤销远端授权，不需要再保存表单。
若页面提示远端撤销未确认，请在 OpenAI 账户中检查已连接应用。本地聊天、独立 API Key、其他账户和重新授权
所需的注册信息会保留。已发出的请求不一定能被撤回。放弃模型草稿或切换至 API Key 不等于断开已授权账户。

## 输出与本地预算

两种连接的聊天、摘要和生成测试均不发送 `max_tokens`、`max_completion_tokens` 或 `max_output_tokens`
等输出上限参数；省略参数不等于无限输出。
旧 `llm.max-tokens` 和 `LLM_MAX_TOKENS` 已退役，现存 TOML 原文可保留但不再生效。模型设置 API 不再接受
`maxTokens` 更新或恢复继承。每日预算、用量计量、最大迭代数和上下文压缩阈值继续有效。

## ChatGPT 连接测试与续聊故障

登录成功和状态栏 LLM 绿灯仅表示本地连接就绪，不能代替“测试连接”的实际生成结果。
如果旧版本首次回复成功、第二轮出现 HTTP 400，可能是助手历史文本使用了错误的 Responses 内容类型；
修复版本会按角色发送历史消息，不需要清空会话或重新登录。修复版本也兼容服务端省略 Content-Type
响应头的有效事件流，但仍须收到完整生成结果才报告成功。遇到失败时先记录测试结果与 HTTP 状态，
不要把登录成功或目录可访问当作模型生成成功。

## API Key 凭据及配置来源

| 操作 | 保存后的含义 |
|---|---|
| 密码框留空 | 保留已有密钥覆盖与继承关系 |
| 输入新密钥 | 替换用户密钥覆盖 |
| 清空密钥 | 写入显式空值，阻止环境变量兜底，新模型工作不可用 |
| 恢复密钥继承 | 删除用户覆盖，恢复 `OPENAI_API_KEY` 等既有解析规则 |
| 非敏感字段恢复继承 | 删除该字段的用户覆盖，采用环境变量或默认值 |

清空和恢复密钥继承分别确认，选中操作只修改草稿，保存后才生效。修改地址后使用旧密钥测试会被拒绝，
需要重新输入目标服务密钥。查询、错误和日志不返回密钥；输入不进入浏览器持久存储。
密钥仍按现有配置方式存放于 TOML，并非系统凭据库；已认证用户可以在高级配置中查看原文。

## ChatGPT 凭据与 Embedding

OAuth 令牌与普通 TOML 分离，保存在 `{memory.dir}/chatgpt-auth/credentials.json`，与账户注册和安装标识一起管理。
POSIX 使用目录 `0700`、文件 `0600`；Windows 使用仅当前用户的 ACL。无法创建或验证这些保护时明确报错，
不会降级写入普通配置。文件权限保护**不等于加密或系统凭据保险库**，不能防御同一操作系统账户下的恶意程序或
拥有更高权限的进程。备份这些文件时同样需要保护访问权限，切勿将其提交到仓库或作为诊断附件分享。

令牌不会返回模型设置或高级配置页面，也不进入浏览器持久存储、提示词或错误日志。本应用只使用自身获发的
客户端身份，不读取浏览器 Cookie、Codex 登录文件或其它应用凭据。授权和模型请求不向自定义 Base URL 转发令牌。

Embedding 仍使用独立的 `embedding.*` API Key 配置，不支持 ChatGPT OAuth，也不会因登录或切换连接自动启用。
未单独设置 Embedding 密钥时，既有规则仍可继承 `llm.api-key`，**绝不继承 OAuth 令牌**。
只登录 ChatGPT 不足以启用向量功能；修改 Embedding 设置或其继承的 API Key 后仍需重启相关组件。

## 保存与高级配置

模型表单只更新实际修改的 LLM 字段，保留无关配置、未知合法键、中文注释、空行和换行风格。
`llm.provider` 默认是 `api-key`，切换后为 `chatgpt`；`llm.chatgpt-account` 与 `llm.chatgpt-model`
分别保存所选账户标识和模型 ID，默认都为空。这三个键仅从 TOML 配置，没有对应环境变量；不要将令牌填入其中。
目标是复杂多行语法或无法安全插入时，保存会拒绝并保留原文，请改用“高级配置”。该限制不影响
原文 API 对合法 TOML 的既有支持。旧通用结构化端点和 Agent 工具仍不承诺注释保真。

保存复用既有提交协调与运行租约。失败时旧文件及运行版本保持不变；正在执行的回答继续使用原模型。
Embedding 继承密钥变化仍需单独重启，不会自动启用原本禁用的功能。同进程写入串行处理，只提交指定
字段；多个窗口同时修改同一字段时后提交者生效，不提供跨进程冲突事务。

模型设置与高级配置切换时如有未保存草稿，会询问是否放弃；取消则保留草稿，确认则读取目标视图的最新
已保存内容。需要保存草稿时先取消切换并保存。高级配置保留原文逐字保存、配置键定位、语言设置及
Embedding 检查；旧 LLM 按钮标明为目录连接检查。

## 开发验证

`node scripts/llm-settings-preview.mjs` 启动仅监听本地回环的内存假数据预览服务，控制台输出临时 URL。
该服务用于检查页面布局及交互，不读写真实配置、不访问供应商；结束后按 Ctrl+C 关闭。
后端测试用本地 HTTP fixture 验证真实接口及运行切换，自动化测试不使用付费请求。
本地协议和 UI 测试不能证明真实账户已获预览资格或可使用订阅额度；真实账户端到端验收需要单独完成浏览器授权、
模型生成、刷新及断开验证，不能用模拟服务结果替代。

预设地址参考：[OpenAI 模型 API](https://developers.openai.com/api/reference/resources/models/methods/list)、
[DeepSeek OpenAI-compatible 地址](https://api-docs.deepseek.com/quick_start/agent_integrations/nanobot/)、[OpenRouter API](https://openrouter.ai/docs/api_reference/overview)。
预设只辅助填写地址，不维护模型能力和价格目录；供应商协议变化时应重新核对文档。
