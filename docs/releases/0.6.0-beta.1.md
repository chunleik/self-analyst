# 0.6.0-beta.1

这是 0.6 本体功能的首个预发布版，用于试用和反馈。由独立 0.6 功能分支发布，main 继续保留 0.5 发布线。

## 主要变化

- 新增“知识”页面：管理项目、主题及别名，查看跨日期、跨应用的活动关系和来源证据。
- 支持项目归属确认、否定、纠错与实体合并，用户决定在重建及重启后保留。
- 接入当前 Wiki、项目记忆、目标、模式与改进记录；来源停用或删除后不再返回旧投影。
- Agent 可通过只读本体工具查询实体和关系，模型热切换后继续可用。
- 包含最新 main 的会话删除确认、遗留配置清理及 CI 验证改进。

## 安装与数据

提供 Windows 10/11 的 NSIS 安装包、便携 ZIP 和各自 SHA-256 校验和。默认使用当前用户的数据目录；完全退出旧版本后，建议先备份整个数据目录再试用。

本体用户实体与纠错保存在 memory 目录的 ontology.db，不能通过删除数据库来代替重建。详情见[个人知识指南](../personal-ontology.md)。

## 证据边界

本体只消费允许的标题派生信息、已有记忆和用户输入，不新增文件正文采集或额外模型调用。推断关系不是完成证明；活动时间为摘要周期，不能相加为任务耗时。歧义、来源缺失及处理上限会明确展示。

本版本标记为 Pre-release，不替代最新稳定版本。
