# SelfAnalyst v0.2.1

本版本完善中英文体验，并提供英文默认 README 与中文文档入口。

## 主要变化

- 完善桌面页面、后端错误提示、活动摘要、行为建议与原生托盘的中英文覆盖。
- 设置页面增加语言选择，支持跟随系统、中文与 English；保存后重启生效。默认跟随系统，未支持的系统语言回退英文。
- 整理前后端与原生壳的语言资源和统一注册机制，补充语言扩展指南及资源一致性验证。
- 默认 README 使用英文，中文说明保留在 README.zh-CN.md；补充语言资源相关的第三方组件说明。

## 从 v0.2.0 升级

1. 退出旧版应用，备份配置与数据。
2. 安装版运行新版安装包，数据继续保存在当前用户应用数据目录。
3. 便携版替换程序文件，保留原 data 目录；若解压到新目录，在应用退出后将原 data 完整复制过去。直接运行 JAR 时继续使用原工作目录。
4. 启动新版，检查配置、历史会话与事件数据。需要切换语言时，在设置中选择并保存，然后重启。

本版本没有新增配置键改名或数据目录迁移要求。用户原文和历史业务数据不会为了语言切换而被翻译或改写。

## 下载文件

- 便携 ZIP：包含 SelfAnalyst.exe、Java 后端和精简 Java runtime，运行数据位于程序旁的 data 目录。
- SelfAnalyst_0.2.1_x64-setup.exe：Windows 用户级安装包，升级或卸载应用文件时保留用户数据。
- 两份对应的 .sha256 文件：用于校验下载内容。

完整桌面体验面向 Windows 10/11，WebView2 由系统提供。
