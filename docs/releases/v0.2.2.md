# SelfAnalyst v0.2.2

本版本新增独立模型设置界面，让模型连接的配置、发现与测试更方便。

## 主要变化

- 提供独立模型设置，支持 OpenAI、DeepSeek、OpenRouter 和自定义 OpenAI-compatible 连接预设，可编辑地址、模型、温度与输出上限。
- 支持按草稿发现模型和发送最小生成请求测试连接；发现与测试不会保存配置，生成测试可能产生少量计费。
- 保存模型设置后，新工作使用新配置，已有回答继续使用原模型版本；定向保存保留其它配置与注释。
- 明确区分密钥保留、替换、清除与恢复继承；修改目标地址后，探测需要重新输入目标服务密钥。
- 补齐英文 README 的配置章节翻译，并修复语言握手超时测试可能无限等待的问题。

## 从 v0.2.1 升级

1. 退出旧版应用，备份配置与数据。
2. 安装版运行新版安装包，继续使用当前用户应用数据目录。
3. 便携版替换程序文件并保留原 data 目录；若解压到新目录，在应用退出后完整复制原 data。直接运行 JAR 时继续使用原工作目录。
4. 启动新版，检查配置与历史数据；需要调整模型连接时，使用独立模型设置，可先测试再保存。

本版本没有新增配置键改名或数据目录迁移要求，原有高级配置编辑入口继续可用。

## 下载文件

- 便携 ZIP：包含 SelfAnalyst.exe、Java 后端和精简 Java runtime，运行数据位于程序旁的 data 目录。
- SelfAnalyst_0.2.2_x64-setup.exe：Windows 用户级安装包，升级或卸载应用文件时保留用户数据。
- 两份对应的 .sha256 文件：用于校验下载内容。

完整桌面体验面向 Windows 10/11，WebView2 由系统提供。
