# SelfAnalyst v0.2.3

本版本新增 Agent 文档生成与另存为能力，正式启用跨平台运行数据准入和独占保护，并上线中英文项目官网。

## 主要变化

- Agent 可根据用户输入、活动记录和分析结果生成 CSV、JSON、XLSX、DOCX、PDF、Markdown 与 PPTX；桌面版可通过系统对话框另存为，Web 版可下载。
- 文档生成支持受控数据导出、不可变版本、失败恢复和格式校验；原始记录由后端分页写入，不经模型逐条转写，监控文件正文仍不会被读取。
- 安装版与标准免安装 ZIP 默认使用 `%LOCALAPPDATA%\com.selfanalyst.desktop` 保存运行数据；在免安装程序旁创建 `portable.marker` 可显式启用程序旁数据。
- 新增数据根独占锁与 `storage-format.json` 格式准入。未知、损坏或无法确认兼容的数据会拒绝启动，不自动迁移或改写。
- 上线中英文项目官网，提供产品介绍、隐私边界和最新 Windows Release 下载入口，并补充英文界面截图与 README 链接。

## 从 v0.2.2 升级

1. 完全退出旧版应用，并备份现有配置和数据；不要让新旧版本同时使用同一数据目录。
2. 安装版运行新版安装包。应用文件升级或卸载不会删除默认用户数据。
3. 标准免安装包默认改用当前用户运行目录。若要继续原地使用旧版程序旁的 `data/`，请在 `SelfAnalyst.exe` 同级创建空文件 `portable.marker` 后再启动。
4. 首次打开选定的数据目录时，程序会先取得独占锁并只读检查兼容性；检查通过后写入格式标记，不搬运业务数据。
5. 启动后检查历史会话、配置和当前数据目录。若程序报告格式未知、损坏或被占用，请保留原数据并根据提示处理，不要手工伪造或降低格式号。

本版本不要求修改模型配置，不会自动查找或迁移其他目录中的旧 portable 数据。文档成果保存在应用管理的数据目录中，用户另存的副本不随会话删除。

## 下载文件

- 便携 ZIP：包含 SelfAnalyst.exe、Java 后端和精简 Java runtime；标准包不预置 `portable.marker`。
- SelfAnalyst_0.2.3_x64-setup.exe：Windows 用户级安装包，运行数据与安装文件分离。
- 两份对应的 `.sha256` 文件：用于校验下载内容。

完整桌面体验面向 Windows 10/11，WebView2 由系统提供。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
