# SelfAnalyst v0.2.4

本版本修复 Windows 安装版启动时提示“无法打开 SelfAnalyst”的问题。

## 修复内容

- 修复 Windows 扩展长度资源路径导致 Java 报 `ClassNotFoundException: com.selfanalyst.App`。桌面壳在启动参数边界转换路径，保留中文、空格和 UNC 共享语义。
- 安装包验证增加真实桌面壳启动检查，覆盖安装资源选择、后端健康握手及窗口创建，避免仅验证 JAR 而漏掉桌面启动故障。

## 升级方式

退出正在运行的 SelfAnalyst 后安装 v0.2.4。安装版的用户数据与安装目录分离，无需删除数据或配置。

安装版与标准免安装版默认使用当前用户应用数据目录；只有非安装分发的 EXE 同级存在 `portable.marker` 时，才使用程序旁数据目录。升级不改变这些规则。

## 下载文件

- `SelfAnalyst-portable.zip`：包含 Java runtime 的免安装包。
- `SelfAnalyst_0.2.4_x64-setup.exe`：Windows 用户级安装包。
- 对应的两份 `.sha256` 文件：用于校验下载内容。

完整桌面体验面向 Windows 10/11，WebView2 由系统提供。
