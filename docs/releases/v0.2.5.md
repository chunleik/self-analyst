# SelfAnalyst v0.2.5

本版本汇总 v0.2.4 之后的桌面体验改进与长期记忆能力。

## 更新内容

- 看板简化为全宽时间轴，集中查看个人活动记录。
- 生成的文档以卡片形式展示在对应会话轮次中，便于查找和保存。
- 支持长期记忆自动总结与会话澄清。
- 修复 Windows 系统托盘悬停提示为空的问题。
- 完善英文和简体中文 README，并修复热更新测试的资源清理。

## 升级说明

退出正在运行的 SelfAnalyst 后安装 v0.2.5。安装版用户数据与安装目录分离，无需删除数据或配置。

便携 ZIP 默认也使用当前用户应用数据目录；需要将数据保存在程序旁时，在 EXE 同级添加 `portable.marker`。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，包含 Java runtime。
- `SelfAnalyst_0.2.5_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
