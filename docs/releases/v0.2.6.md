# SelfAnalyst v0.2.6

本版本汇总 v0.2.5 之后的会话图片输入、HTML/SVG 文件输出与桌面修复。

## 更新内容

- 支持选择或粘贴图片到会话，预览后发送；图片随会话保存，刷新或重启后仍可查看。图片理解需要配置支持图片输入的对话模型。
- 支持生成自包含的交互 HTML 页面和 SVG 文件，通过会话文件卡片下载，并可继续修改、保留历史版本。
- 修复桌面端打开数据目录时缺少原生命令权限的问题。
- 将 jsoup 升级至 1.23.1。

## 升级说明

退出正在运行的 SelfAnalyst 后安装 v0.2.6。安装版用户数据与安装目录分离，无需删除数据或配置。

便携 ZIP 默认也使用当前用户应用数据目录；需要将数据保存在程序旁时，在 EXE 同级添加 `portable.marker`。

会话图片仅来自用户主动选择或粘贴并确认发送的输入。发送后，图片内容会随问题传给配置的对话模型。HTML/SVG 成果通过附件下载，应用内不会自动执行或打开这些文件。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，包含 Java runtime。
- `SelfAnalyst_0.2.6_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
