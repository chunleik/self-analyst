# SelfAnalyst v0.2.7

本版本修正活动时长与统计日口径，并新增桌面标题栏帮助菜单。

## 更新内容

- 活动耗时扣除 AFK（非活跃）区间，跨统计日的窗口事件按实际交集计时；重叠的 AFK 区间不会重复扣除。
- 统计日从本地时间每日 04:00 开始，次日 04:00 结束；凌晨四点前归属前一统计日，看板、Wiki 和行为建议采用一致口径。
- 未识别应用活动单独展示；AFK 数据缺失或覆盖不足时明确标注估计口径。
- 桌面标题栏新增帮助菜单，提供使用指南、反馈问题和关于信息；主导航移除重复品牌名称。Web 版在导航保留品牌并提供帮助入口，两种入口均支持中英文和键盘操作。

## 升级说明

1. 正常退出旧版 SelfAnalyst，并备份现有配置和数据，再安装或解压 v0.2.7；新旧版本不要同时使用同一数据目录。
2. 旧统计口径的桌面快照会失效，首次刷新使用新口径本地事实。Wiki 数据库迁移至 schema 4，迁移前在同目录生成 `llm-wiki.db.before-statistics-v4.bak`。
3. 旧 Wiki 摘要保留用于追溯，但不进入新口径默认查询、父级摘要和语义检索。启用既有历史补算时，后台逐步重算并保存进度；重算遵守现有模型预算和重试设置，可能产生模型调用。关闭 Wiki 或历史补算的设置仍然有效。永久原始事件不会被修改。
4. 如需回退，先退出新版并另行备份当前派生数据库，再恢复升级前的 Wiki 数据库备份，使用匹配旧数据格式的程序；不要用旧程序直接打开 schema 4 数据库。

安装版用户数据与程序目录分离。标准便携 ZIP 默认使用当前用户应用数据目录；需要使用程序旁数据目录时，在 EXE 同级添加 `portable.marker`。

详见[活动统计与升级说明](https://github.com/chunleik/self-analyst/blob/v0.2.7/docs/activity-statistics.md)。

- `SelfAnalyst_0.2.7_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
