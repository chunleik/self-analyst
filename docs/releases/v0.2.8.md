# SelfAnalyst v0.2.8

本版本改进桌面帮助与发布体验，并更新双语入门文档。

## 更新内容

- 修复桌面壳图标资源，改善 Windows 包中的图标显示。
- 帮助菜单新增手动检查更新，可查看当前版本与最新稳定版本，并从发布页面获取安装包；应用不会自动下载或安装。
- 完善中英文 README 的安装、启动和首次使用说明，保持两种语言内容一致。

## 升级说明

1. 正常退出旧版 SelfAnalyst，并备份现有配置和数据，再安装或解压 v0.2.8；新旧版本不要同时使用同一数据目录。
2. 安装版用户数据与程序目录分离。标准便携 ZIP 默认使用当前用户应用数据目录；需要使用程序旁数据目录时，在 EXE 同级添加 `portable.marker`。
3. 如需回退，先退出新版并备份当前数据，再使用匹配版本的程序。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，包含 Java runtime。
- `SelfAnalyst_0.2.8_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
