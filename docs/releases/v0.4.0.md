# SelfAnalyst v0.4.0

本版本围绕配置体验改进：配置窗口重排为三个页签、修复打开数据目录的权限链路，并停用单次输出上限；包含模型设置接口的不兼容变更。

## 更新内容

- 配置窗口分为 **模型设置**、**高级配置**、**运行数据** 三个页签，默认打开模型设置，按所选页签加载数据，跨页签切换时保留草稿确认。
- 模型设置按连接设置、模型与生成、测试及运行状态分组：新输入的 API Key 可显隐，模型发现结果可直接点选，保存操作栏在滚动时始终可见。
- 运行数据成为独立只读页签：展示真实运行目录、数据目录、运行模式、四类存储容量及合计；提供刷新、桌面端原生打开数据目录、迁移备份确认清理与失败重试；无迁移备份时不再显示底部清理提示。
- 高级配置重排为顶部文件信息与辅助工具、中部原文编辑区与独立运行信息、底部保存操作栏，适配窄窗口与长错误文本。
- 修复打开数据目录命令的权限链路：补齐受管页面授权，使桌面端"打开数据目录"恢复可用。
- 修复长时间运行后 Agent 将启动时间误作当前时间的问题：每轮对话向模型提供该轮的本地时间与时区。
- **停用单次输出上限（BREAKING）**：聊天、摘要与生成测试均不再发送 `max_tokens` 等输出上限参数，由模型服务端自行决定输出限制；`llm.max-tokens` 配置与 `LLM_MAX_TOKENS` 环境变量退役，已有 TOML 原文保留但不再生效；模型设置 API 不再返回或接受 `maxTokens` 字段。每日预算、用量计量、迭代次数限制与上下文压缩保持不变。

## 从 v0.3.0 升级

**本版本无存储格式变更，升级前仍建议常规备份数据目录。**

1. 正常退出旧版 SelfAnalyst，安装或解压 v0.4.0 后直接使用，数据与配置无需迁移。
2. 输出上限相关调整无需手动处理：已有 TOML 中的 `llm.max-tokens` 行保留但不生效，可在高级配置中自行删除；`LLM_MAX_TOKENS` 环境变量被忽略。
3. 依赖模型设置 API 的外部脚本请注意：请求或响应中的 `maxTokens` 字段已移除，旧客户端显式提交该字段会按不支持字段拒绝。
4. 省略输出上限参数不等于服务端无限输出：如需控制成本，请通过模型服务端的限额设置或本应用的每日预算管理。
