# SelfAnalyst v0.5.0-beta.1

这是面向试用的预发布版本，不替代 v0.4.0 稳定版。应用内「检查更新」只比较最新稳定版，不会提示安装本版本；需要从本版本的 GitHub Release 页面手动下载。

## 更新内容

- 每日摘要使用带时间、来源和有效时长的标题事实，减少重复窗口挤占预算，同一应用里的不同主题更容易进入摘要。正文聚焦项目与工作主题，时长等统计留在本地指标中。
- 摘要合成可以按主题规划持久化，并在预算内重试；中断后可以继续，而不必每次从头生成。
- 桌面端不再展示合并事件状态。

## 从 v0.4.0 升级

1. 正常退出正在使用的 SelfAnalyst，并先备份数据目录。
2. 从本预发布的 Release 页面下载便携 ZIP 或 NSIS 安装包，不要和 v0.4.0 同时使用同一数据目录。
3. 试用结束后，稳定版仍以 GitHub 最新正式 Release 为准。v0.4.0 的检查更新不会把本试用版当作可用更新。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，包含 Java runtime。
- `SelfAnalyst_0.5.0-beta.1_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
