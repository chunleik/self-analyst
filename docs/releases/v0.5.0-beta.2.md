# SelfAnalyst v0.5.0-beta.2

这是面向试用的预发布版本，不替代 v0.4.0 稳定版。应用内「检查更新」只比较最新稳定版，不会提示安装本版本；需要从本版本的 GitHub Release 页面手动下载。

## 更新内容

相对 [v0.5.0-beta.1](v0.5.0-beta.1.md)：

- 摘要更聚焦有效活动：噪声窗口（锁屏、搜索、新标签页等）本地过滤，主题按有效时长排序，半天及以上摘要收敛为一句主线、最多三个主题。
- 上层摘要对子摘要脱敏：内网地址、会议号等敏感片段在进入模型前替换；可按应用与网站排除，应用权重中不出现被排除应用。
- 浏览器 chrome 探测：在无障碍可用时写入 `url_host` 与 `private_browsing`（不存完整网址或控件树），用于网站排除与无标题标记的无痕识别；已保存摘要按同样文本规则本地脱敏，不调用模型。

## 从上一版本升级

1. 正常退出正在使用的 SelfAnalyst，并先备份数据目录。
2. 从本预发布的 Release 页面下载便携 ZIP 或 NSIS 安装包，不要和稳定版或其他试用版同时使用同一数据目录。
3. 试用结束后，稳定版仍以 GitHub 最新正式 Release 为准。v0.4.0 的检查更新不会把本试用版当作可用更新。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，包含 Java runtime。
- `SelfAnalyst_0.5.0-beta.2_x64-setup.exe`：Windows 用户级安装包。
- 对应 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
