# SelfAnalyst v0.6.0

0.6.0 是包含个人知识与本体功能的正式版本，接续 0.5.0 稳定版及 0.6.0-beta.1 预览版。应用内「检查更新」可发现本版本，下载与安装仍由用户手动完成。

## 更新内容

- 新增「知识」页面：管理项目、主题及别名，查看跨日期、跨应用的活动关系和来源证据。
- 支持关联确认、否定、项目归属纠错及同类型手工实体合并；用户决定在重建和重启后保留。
- 接入当前 Wiki、有效项目记忆、目标、模式与改进记录。来源停用、删除或失效后，查询不再返回旧投影。
- 聊天可通过只读本体工具查询实体与关系，模型热切换后继续可用。本体管理与重建可离线运行，不增加模型或 embedding 调用。
- 更改界面语言后可点击重启操作使新语言生效；修复看板重复请求模型的问题，明确当前及累计 Token 的统计口径。

本体只消费允许的标题派生信息、已有记忆和用户输入，不新增文件正文采集。推断或用户确认的关系不代表任务完成或目标达成；活动时间是摘要周期，不能相加为项目耗时。歧义、来源缺失及处理上限会在界面明确展示。详见[个人知识指南](../personal-ontology.md)。

## 升级与数据

1. 使用托盘菜单完全退出旧版本，先备份整个用户数据目录。
2. 下载本版本安装包，或将便携 ZIP 解压到应用目录后运行 `SelfAnalyst.exe`。避免不同版本同时使用同一数据目录。
3. 从 0.5 升级时，原有事件、Wiki 和记忆继续可用，独立本体库自动初始化；从 0.6.0-beta.1 升级时继续使用已有本体数据。

本体用户实体、别名、合并和纠错保存在配置 memory 目录中的 `ontology.db`，必须随其他用户数据一起备份。点击「重建关联」可更新派生投影并保留用户决定；不要通过删除数据库代替重建。回退旧版时保留本体库，以便再次升级后继续使用。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，自带 Java runtime。
- `SelfAnalyst_0.6.0_x64-setup.exe`：Windows 用户级 NSIS 安装包。
- 对应 `.sha256` 文件：下载校验和。

默认使用当前用户的应用数据目录；便携包添加 `portable.marker` 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime；发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
