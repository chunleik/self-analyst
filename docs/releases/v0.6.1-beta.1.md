# SelfAnalyst v0.6.1-beta.1

这是基于 v0.6.0 之后最新 main 的预发布版本，供试用知识页改进和兼容性更新。它不替代 v0.6.0 稳定版；应用内「检查更新」只查询最新稳定版，不会提示安装本版本，请从本预发布的 GitHub Release 页面手动下载。

## 更新内容

相对 [v0.6.0](v0.6.0.md)：

- 优化「知识」页面的筛选区、实体列表、详情与证据展示，统一主题颜色、焦点状态和弹窗居中；点击实体或关系后，列表选中高亮即时同步。
- 修复桌面文档校验和的十六进制格式化实现，使其兼容 sha2 0.11；SHA-256 校验规则和结果保持不变。
- 更新 Java、桌面壳与 Windows accessibility sidecar 的依赖及构建工具，包括 AgentScope、Jackson、Tauri CLI 和 UI Automation 相关组件。

本次发布不新增数据采集范围，不改变本体数据格式，也不新增模型调用。个人知识、本体关系与用户纠错能力沿用 v0.6.0，详见[个人知识指南](../personal-ontology.md)。

## 试用与升级

1. 使用托盘菜单完全退出旧版，并备份整个用户数据目录，包括 memory 目录中的 `ontology.db`。
2. 下载本版本的 NSIS 安装包，或将便携 ZIP 解压后运行 `SelfAnalyst.exe`；不要让稳定版和预发布版同时使用同一数据目录。
3. 重点检查知识页筛选、实体及关系切换、弹窗和文档操作。预发布版可能仍有问题；遇到问题请保留复现步骤，回退前再次备份试用期间的数据。

默认使用当前用户的应用数据目录；便携包添加 `portable.marker` 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。本版本不要求手动迁移数据；请勿通过删除数据库替代备份或重建关联。

## 分发包

- `SelfAnalyst-portable.zip`：Windows 免安装包，自带 Java runtime。
- `SelfAnalyst_0.6.1-beta.1_x64-setup.exe`：Windows 用户级 NSIS 安装包。
- 两份对应的 `.sha256` 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
