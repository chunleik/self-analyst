# SelfAnalyst v0.6.1-beta.10

这是接续 v0.6.1-beta.9 的预发布版本，新增 ChatGPT 登录与 Responses 模型连接。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

**此功能使用 OpenAI 的 Sign in with ChatGPT 开源客户端预览。拥有 ChatGPT 订阅不代表拥有 OpenAI API 额度，也不保证账户已获预览资格或直接模型访问权限。** 套餐、地区、模型、配额与服务条款以 OpenAI 服务端为准；本应用不承诺免费或无限调用。真实账户端到端验证尚未完成，建议先在独立测试数据目录试用。

## 升级前请完整备份

本轮没有新增数据库迁移，继续使用 beta.8 已引入的 Wiki schema 5。由 beta.8 或 beta.9 升级到本版不会再次引入 schema 4→5；从 beta.7 或更早版本首次升级到 schema 5 时，旧版不能直接打开升级后的 Wiki 数据库。

升级前通过托盘完全退出旧版，备份完整运行数据根、配置文件和所有配置到运行数据根之外的数据目录（包括事件、记忆和索引目录）。不要让稳定版和预发布版同时使用同一数据目录。首次 schema 5 升级会先创建并核验 `llm-wiki.db.before-summary-repair-v5.bak`，再进行事务迁移；自动 Wiki 备份只覆盖 Wiki，不能代替整个应用的备份。没有兼容且可恢复的升级前完整备份时，不应尝试降级，也不要手工修改 SQLite `user_version`。

新增 ChatGPT 凭据文件也可能包含在完整备份中。请保护备份的访问权限，不要将凭据文件上传到仓库或作为诊断附件分享。

## 更新内容

### ChatGPT 登录与多账户

- “模型设置”新增 **API Key / ChatGPT 登录** 两种连接方式，可保留一个独立 API Key 连接与多个 ChatGPT 账户，同一时间仅启用一个连接。
- 使用系统浏览器打开 OpenAI 授权页面，通过 PKCE、state/nonce 和本机回环回调完成授权；支持取消、过期、重新登录与账户断开。不读取浏览器 Cookie、Codex 登录文件或其他应用凭据。
- 授权后可加载账户允许的模型目录，也可手工填写服务端支持的模型 ID；ChatGPT 模型与 API Key 模型分别保存，没有固定默认模型。
- 登录和生成测试不会自动保存活动连接，仍需点击“保存并应用”。新工作使用新连接，已在执行的工作继续使用原运行配置。
- 断开账户会清除本地 OAuth 令牌并尝试撤销远端授权；若未确认撤销，界面提示用户到 OpenAI 检查。独立 API Key、其他账户与本地聊天不会因此删除。

### Responses、工具调用与额度暂停

- ChatGPT 连接使用固定 OpenAI Responses 接口，支持流式文本、工具调用与工具结果续轮，并在后续请求中保留服务端返回的加密 reasoning 项。图片与工具能力仍受所选模型及预览协议限制。
- 不向自定义 Base URL 转发 OAuth 令牌，也不使用 API Key 表单中的地址、模型或温度。单次 Responses 请求不做传输层自动重试，不因权限、限流或网络失败自动切换账户或退回 API Key；后台任务仍按既有失败分类与调度规则处理后续重试。
- 账户遇到限流或额度耗尽时，在本次应用进程中暂停该账户的后续模型调用；服务端额度恢复后，主动运行成功的生成测试可恢复调用。本地 token 统计不是 OpenAI 剩余额度查询。
- “测试生成连接”只发送固定短提示，不携带会话、活动标题、文件元数据或工具上下文，但会使用服务端分配的额度。测试通过不保证长对话、图片或全部工具均可用。

### 凭据存储与独立 Embedding

- OAuth 令牌与普通 TOML 分离，保存在 `{memory.dir}/chatgpt-auth/credentials.json`，通过 POSIX 目录/文件权限或 Windows 当前用户 ACL 保护；无法创建或验证保护时明确失败，不降级写入普通配置。
- **凭据文件未加密，权限保护不等于系统凭据保险库。** 它不能防御同一操作系统账户下的恶意程序或更高权限进程。令牌不返回设置界面，不写入浏览器持久存储、提示词或错误日志。
- Embedding 继续使用独立的 `embedding.*` API Key 配置，不支持 ChatGPT OAuth，不会因登录或切换连接自动启用。未单独配置时仍可按既有规则继承 `llm.api-key`，绝不继承 OAuth 令牌；相关配置变化仍需重启对应组件。
- Windows 便携运行时模块列表补入 `jdk.httpserver`，供本机 OAuth 回调使用。该配置的本地静态回归通过不等于真实便携包构建或运行验证通过。

本轮不扩大内容或文件采集范围。操作、外发数据与凭据边界见[模型设置指南](https://github.com/chunleik/self-analyst/blob/v0.6.1-beta.10/docs/llm-settings.md)和[隐私说明](https://github.com/chunleik/self-analyst/blob/v0.6.1-beta.10/PRIVACY.md)。

版本准备时，功能工作区已完成以下本地验证，测试仅使用合成数据与协议夹具，不访问真实用户数据库或收费模型：

- Maven 相同工作目录的 Node 测试共 332 项，300 通过、32 项条件跳过，0 失败；版本准备时重新运行模型设置、ChatGPT UI 和运行时打包配置三组针对性 Node 测试，37 项全部通过。
- 本机缺少 `ct.sym`，上述 Java 测试使用同一 JDK 21 的临时 wrapper，把 `--release 21` 转为 `-source 21 -target 21`。仓库构建配置没有为此改写；该结果不提供 `--release` 的同等标准 API 限制，不能代替完整 JDK 21 的标准构建。
- 13 个版本文件逐项解析与差异核对通过，原发布通道脚本确认 `prerelease`；版本准备的 OpenSpec 全量严格校验与差异检查通过。

**版本准备时尚未完成：** 精确新提交的 Windows 必需检查、标准 JDK 21 构建、Rust/Cargo 测试与 Clippy、Windows ACL 实机、原生 UI/系统浏览器、WebView2 视觉验收，以及 tag 工作流的便携 ZIP/NSIS 构建与安装验证。远端 CI 和 tag 发布门禁必须分别核对本次精确提交，不能沿用旧提交结果。

真实 ChatGPT 账户的浏览器授权、套餐与直接模型权限、模型发现、生成、刷新及断开端到端验收也尚未完成。协议夹具和 DOM 测试不能证明真实账户已获预览资格，也不替代原生视觉与 Windows 安装验收；相关功能 OpenSpec change 保持活动，不因发版标记为全部完成。

## 安装、试用与回退

1. 完成退出与完整备份后，下载安装包，或把便携 ZIP 解压到新目录后运行 `SelfAnalyst.exe`。默认使用当前用户应用数据目录；添加 `portable.marker` 后使用程序旁数据目录。
2. 优先使用独立测试数据目录，在“模型设置”选择“ChatGPT 登录”，添加账户并核对官方授权页面。仅在 OpenAI 页面输入登录信息，不向本应用提供密码或手工粘贴令牌。
3. 加载模型或填写已获授权的模型 ID，按需运行生成测试，再“保存并应用”。缺少预览权限时检查账户资格，或主动切换回 API Key；不要把登录成功当成模型生成已可用。
4. 如需回退，先退出新版并另存当前完整数据，再将兼容的升级前完整备份恢复到隔离目录，显式使用旧版打开该目录。不要只把旧 Wiki 库覆盖进混有新版聊天、索引和事件状态的目录。
5. 恢复旧备份不包含备份后的活动、聊天和修订，请保留新版数据副本；无可用备份时保留新版，不承诺无损降级。回退或卸载应用不等于撤销 OpenAI 授权，需要时先断开账户并确认远端撤销状态。

升级或卸载应用文件不会删除默认用户数据。更多备份与回退边界见[运行数据说明](https://github.com/chunleik/self-analyst/blob/v0.6.1-beta.10/docs/runtime-storage.md#摘要修复存储升级与回退)。
