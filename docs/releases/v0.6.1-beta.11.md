# SelfAnalyst v0.6.1-beta.11

这是接续 v0.6.1-beta.10 的预发布版本，汇总最新 main 中的 ChatGPT 刷新可靠性修复、AgentScope 2.0.4 兼容与依赖更新。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

**ChatGPT 连接仍使用 OpenAI 的 Sign in with ChatGPT 开源客户端预览。** 拥有订阅不等于拥有 OpenAI API 额度，也不保证已获预览资格或直接模型访问权限。套餐、地区、模型、配额及条款以 OpenAI 服务端为准，本应用不承诺免费或无限调用。真实账户端到端及系统浏览器/WebView2 人工视觉验收仍未完成，建议先用独立测试数据目录试用。

## 更新内容

### ChatGPT 刷新与身份校验

- 刷新请求不再长期占用凭据存储锁。网络刷新、身份校验或远端撤销等待期间，状态查询与其它账户的凭据读取不必等待该网络请求。
- 使用独立刷新锁协调进程内及跨进程刷新；锁等待共享最长 90 秒期限，超时或中断返回受限错误，不发起重复刷新、不切换账户。
- 服务端轮换后的 refresh token 先安全落盘，再完成身份校验；校验暂时不可用时保留新凭据，后续调用继续校验，避免重复刷新丢失有效令牌。身份未验证前不会把新 access token 用于模型请求。
- 刷新、断开与重新登录交错时，旧请求不能覆盖新登录或恢复已断开的凭据。远端撤销失败仍清理本地 token，并明确提示撤销未确认。
- ChatGPT 摘要和其他 plain 调用遵循调用方的超时设置，内部上限为 5 分钟；对话模型保留 45 秒超时。这不保证服务端一定在时限内完成，也不会自动退回 API Key。

### AgentScope 与取消隔离

- 升级至 AgentScope 2.0.4，适配其单次运行句柄，保持每次调用的取消和资源清理边界。
- 增补取消、并发与 session-state 回归，防止旧运行的清理干扰随后开始的运行；不承诺即时中断所有远端模型计算。

### 依赖与验证工具

- 更新 Jackson 2.22.4、Logback 1.6.6、Log4j-to-SLF4J 2.26.1、应用搜索 Lucene 10.6.0、JGit 7.8.0.202609011348-r，以及桌面端及构建工具的锁定依赖。
- Neo4j 测试 harness 更新至 5.26.32，其测试依赖继续独立使用 Lucene 9.11.1，避免与应用搜索的 Lucene 10 混用。本包不会安装 Neo4j 服务。
- 摘要修复界面冒烟脚本等待按钮加载后再单次点击，减少加载竞争造成的误报，不放宽生产行为或跳过检查。

本轮没有新增采集能力。文件采集仍不读取普通文件正文，除安全解析 .gitignore 外仅收集显式配置目录内的文件系统元数据；不持久化 UIA 正文、截图或音频。API Key 与 ChatGPT 连接保持独立，Embedding 不使用 OAuth 令牌。OAuth 文件仍由当前用户文件权限保护，未做应用层加密，不能防御同一系统账户下的恶意程序或更高权限进程。

## 升级前备份与凭据兼容

本轮没有新增数据库迁移，继续使用 beta.8 已引入的 Wiki schema 5。从 beta.8、beta.9 或 beta.10 升级不会再次引入 schema 4→5；从 beta.7 或更早版本首次升级时，旧版不能直接打开升级后的 Wiki 数据库。

升级前通过托盘完全退出旧版，备份完整运行数据根、配置，以及配置到运行数据根之外的事件、记忆和索引目录。不要让不同版本同时使用同一数据目录。首次 schema 5 升级自动生成的 Wiki 备份只覆盖 Wiki，不能代替整个应用的备份；不要手工修改 SQLite user_version，也不要在没有兼容完整备份的情况下尝试降级。

本轮凭据目录新增独立刷新锁，并扩展轮换后“身份待校验”状态。旧版本不具备相同的刷新协调和校验语义，**不要让 beta.10 与本版共用凭据目录，也不要把新版凭据直接复制回旧版**。备份可能包含 OAuth 凭据，应保护访问权限，不上传到仓库或诊断附件。

如需回退且使用 ChatGPT，先在新版断开账户并核对远端撤销；随后退出新版并保留当前完整数据副本，将兼容的升级前备份恢复到隔离目录后再使用旧版，并在旧版重新授权。恢复旧备份不保证旧 refresh token 仍有效。没有可恢复备份时不要承诺无损降级。卸载应用或恢复数据不等于撤销 OpenAI 授权。

## 安装与分发包

完整退出旧版并完成备份后，下载安装包，或将便携 ZIP 解压到新目录并运行 SelfAnalyst.exe。默认使用当前用户应用数据目录；仅在主动添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。

本次 tag 发布门禁通过后提供：

- SelfAnalyst-portable.zip：免安装包，自带 Java 21 runtime，包含 OAuth 回环回调所需的 jdk.httpserver。
- SelfAnalyst_0.6.1-beta.11_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime；包内不含 PaddleOCR、Tesseract、Whisper 或语音模型。
