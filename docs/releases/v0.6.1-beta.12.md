# SelfAnalyst v0.6.1-beta.12

这是接续 v0.6.1-beta.11 的预发布版本，交付 [PR #141](https://github.com/chunleik/self-analyst/pull/141) 的 ChatGPT 生成协议兼容与模型设置文案修复。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- ChatGPT 生成接口返回 HTTP 200 且缺少 Content-Type 时，继续读取并校验 SSE 事件；只有收到有效完成事件才报告成功。明确声明非 SSE 的响应仍被拒绝，空响应、普通 JSON、HTML、只有文本增量、失败及不完整事件均不算成功。保留原有响应大小、超时及单次请求限制。
- 补齐 ChatGPT 模型、账户与连接方式校验错误的中英文文案。模型未填写时提示填写模型 ID，或加载列表后选择再保存，不再直接显示内部错误键；保存失败时保留设置草稿。

本轮没有新增数据库迁移、采集能力或外发数据字段，也没有更改第三方依赖。API Key 与 ChatGPT 连接继续独立，Embedding 不使用 OAuth 令牌。文件采集仍不读取普通文件正文，除安全解析 .gitignore 外仅收集显式配置目录内的文件系统元数据；不持久化 UIA 正文、截图或音频。

## ChatGPT 使用与验收边界

ChatGPT 连接仍使用 OpenAI 的 Sign in with ChatGPT 开源客户端预览。拥有订阅不等于拥有 OpenAI API 额度，也不保证已获预览资格或直接模型访问权限；套餐、地区、模型、配额及条款以 OpenAI 服务端为准，本应用不承诺免费或无限调用。

PR #141 的验证记录包含一次使用修复代码与 gpt-6.1-sol 的真实账户最小生成验证，收到了有效文本、完成状态和 usage。该结果仅证明当次模型生成链路，不替代浏览器登录、刷新、断开、工具续轮、不同账户套餐及系统浏览器/WebView2 人工视觉验收；这些未完成验收仍保持未完成，相关功能 change 不因发版归档。

## 升级与回退

升级前通过托盘完全退出旧版，备份完整运行数据根、配置，以及配置到运行数据根之外的事件、记忆与索引目录。不要让不同版本同时使用同一数据或凭据目录。建议先用独立测试数据目录试用。

本轮没有新增数据格式变化，继续沿用 Wiki schema 5；从 beta.7 或更早版本首次升级时，旧版不能直接打开升级后的 Wiki 数据库。首次 schema 5 升级自动生成的 Wiki 备份不能代替完整备份，不要手工修改 SQLite user_version，也不要在没有兼容完整备份的情况下尝试降级。

beta.11 已引入凭据刷新锁与轮换后“身份待校验”状态。不要将新版凭据复制回 beta.10 或更早版本。凭据文件由当前用户权限保护，未做应用层加密，不能防御同一系统账户下的恶意程序或更高权限进程；备份可能包含凭据，须保护访问权限，不上传到仓库或诊断附件。需要回退时，先在新版断开 ChatGPT 账户并核对远端撤销，再退出新版并保留当前完整数据副本，将兼容的升级前完整备份恢复到隔离目录并重新授权。恢复旧备份会丢失备份后新增的数据。旧备份中的 refresh token 不保证仍有效，卸载或恢复数据不等于撤销 OpenAI 授权。

## 验证状态

本次版本准备以 PR #141 合并后的 af186a6 为基线，该 PR 最新提交的 Windows 全量验证和三平台数据守卫已通过。13 个版本文件逐项解析与差异核对通过；发布通道脚本输出 prerelease。云端 Node 定向测试 68 项，45 通过、23 项条件跳过；完整 Node 测试 340 项，308 通过、32 项条件跳过，均无失败。OpenSpec 归档前全量 strict 40/40 与差异检查通过。历史 PR 中的测试结果不能替代精确版本提交的 CI 和发布 tag 的质量门禁。

版本 PR 必须通过最新提交的 Windows 全量验证和三平台数据守卫；发布 tag 继续执行标准 JDK 21 Java/Node 测试、Rust/Clippy、Windows UIA、JAR 冒烟及便携 ZIP、NSIS 安装/重装/启动/卸载验证。所有打包由 GitHub Actions 远端完成，不在本地打包。此文件记录版本准备时的计划，发布页将在实际完成后补充真实结果，不将尚未执行的检查写成通过。自动化验证不替代人工视觉与完整真实账户端到端验收。

## 安装与分发包

完整退出旧版并完成备份后，下载安装包，或将便携 ZIP 解压到新目录并运行 SelfAnalyst.exe。默认使用当前用户应用数据目录；主动添加 portable.marker 后才使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。

发布门禁通过并校验后提供：

- SelfAnalyst-portable.zip：自带 Java 21 runtime 的免安装包，包含 OAuth 回环回调所需的 jdk.httpserver。
- SelfAnalyst_0.6.1-beta.12_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime；包内不含 PaddleOCR、Tesseract、Whisper 或语音模型。
