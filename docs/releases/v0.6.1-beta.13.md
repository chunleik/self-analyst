# SelfAnalyst v0.6.1-beta.13

这是接续 v0.6.1-beta.12 的预发布版本，包含应用隐私设置、ChatGPT 续聊修复和短暂无前台窗口时的采集连续性修复。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- **应用隐私设置（#143、#144）**：新增“设置 → 隐私”，可从近 30 天窗口活动搜索应用，或手工输入完整可执行文件名，选择“不采集”或“仅对模型隐藏”；也可按网站关键词隐藏模型输入。成功保存后热生效，无需重启或新建会话。应用名按完整 exe 名匹配、不区分大小写，不同可执行文件变体需分别添加。
- **ChatGPT 续聊修复（#145）**：修复助手历史文本类型错误导致第二轮 HTTP 400，保留用户、助手和工具消息的角色及顺序，不需要清空会话或重新登录。beta.12 已交付的缺失 Content-Type 有效 SSE 兼容继续保留。
- **采集连续性修复（#146）**：短暂无前台窗口或窗口句柄为 0 时，不再误删允许应用的待重试内容或切断采集会话；旧快照及在途采集结果仍会失效，恢复后重新采集。明确排除应用时仍丢弃待重试事件并断开会话，不补发排除期间的记录。

本轮没有新增数据库迁移、持久化格式或产品运行时依赖变化。文件采集仍只收集显式配置目录内的文件系统元数据，除安全解析 .gitignore 外不读取普通文件正文；不持久化 UIA 正文、截图或音频。

## 隐私设置的范围

“不采集”停止匹配应用的窗口/内容事件及 UIA 查询，AFK 保持不变；排除期间没有这些本地记录，之后无法补回。“仅对模型隐藏”保留本地记录与展示。网站隐藏只影响模型可见性，不停止浏览器采集；没有标记的无痕窗口无法可靠识别。

两份应用清单合并用于新的模型输入，也会过滤匹配的历史事件。规则不删除原记录、不改写已有摘要、会话中已看到的内容或旧工具结果。正在执行的处理使用开始时的策略快照，新规则不取消已发出的请求。文件元数据采集及用户主动发送的聊天文字、附件不由应用隐私清单自动清理。

**数值 AQL 聚合及结果元数据仍可能包含隐藏事件的时长、数量等信息，不能把“仅对模型隐藏”视为完全隔离或防止推断。** Agent 执行 AQL 前会拒绝用 tag 改写 app、title、context_title、url_host、private_browsing 等隐私识别字段；本机直接 AQL 保持原有功能。文档事件投影只导出可见事件，recordCount 是实际导出行数，privacyFilteredCount 是过滤数量，complete: true 表示过滤后的投影完整。

## ChatGPT 使用与验收边界

ChatGPT 连接仍使用 OpenAI 的 Sign in with ChatGPT 开源客户端预览。订阅不等于 API 额度，也不保证预览资格或直接模型访问权限；套餐、地区、模型、配额及条款以 OpenAI 服务端为准，本应用不承诺免费或无限调用。API Key 与 ChatGPT 连接独立，Embedding 不使用 OAuth 令牌。

PR #145 的既有验证记录包含真实账户连续两轮固定提示成功及桌面“测试生成连接”成功；这些是修复验证，不等于本次发布包的完整真实账户端到端验收。完整浏览器 OAuth、账户切换、刷新和断开等验收仍未全部完成，相关功能 change 保持活动。本次发版没有重新执行真实账户调用。

## 升级与回退

升级前通过托盘完全退出旧版，备份完整运行数据根、配置，以及配置到运行数据根之外的事件、记忆与索引目录。不要让不同版本同时使用同一数据或凭据目录。建议先用独立测试数据目录试用。

继续沿用 Wiki schema 5；从 beta.7 或更早版本首次升级时，旧版不能直接打开升级后的 Wiki 数据库。首次 schema 5 升级自动生成的 Wiki 备份不能代替完整备份，不要手工修改 SQLite user_version，也不要在没有兼容完整备份的情况下尝试降级。回退旧版不会保留新版新增的隐私保护，应重新核对采集和模型设置。

beta.11 已引入凭据刷新锁与轮换后“身份待校验”状态。不要将新版凭据复制回 beta.10 或更早版本。凭据文件由当前用户权限保护，未做应用层加密，不能防御同一系统账户下的恶意程序或更高权限进程；备份可能包含凭据，须保护访问权限，不上传到仓库或诊断附件。需要回退时，先在新版断开 ChatGPT 账户并核对远端撤销，再退出新版并保留当前完整数据副本，将兼容的升级前完整备份恢复到隔离目录并重新授权。恢复旧备份会丢失备份后新增的数据。旧备份中的 refresh token 不保证仍有效，卸载或恢复数据不等于撤销 OpenAI 授权。

## 验证与发布门禁

版本准备以 PR #146 合并后的 e6d0e24 为基线；#143、#144、#145、#146 均已合并，准备前 open PR 列表为空。#146 精确 head 06d75b3 的 Windows 全量验证、三平台数据守卫及 Linux 隐私界面验证全部成功。历史测试结果不能替代精确版本提交的 CI 和发布 tag 的质量门禁。

版本 PR 必须通过最新提交的全部 CI；发布 tag 继续执行标准 JDK 21 Java/Node 测试、Rust/Clippy、Windows UIA、JAR 冒烟及便携 ZIP、NSIS 安装/重装/启动/卸载验证。所有打包由 GitHub Actions 远端完成，不在本地打包。此文件记录版本准备时的计划，发布页将在实际完成后补充真实结果，不将尚未执行的检查写成通过。自动化验证不替代人工视觉与完整真实账户端到端验收。

## 安装与分发包

完整退出旧版并完成备份后，下载安装包，或将便携 ZIP 解压到新目录并运行 SelfAnalyst.exe。默认使用当前用户应用数据目录；主动添加 portable.marker 后才使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。

发布门禁通过并校验后提供：

- SelfAnalyst-portable.zip：自带 Java 21 runtime 的免安装包，包含 OAuth 回环回调所需的 jdk.httpserver。
- SelfAnalyst_0.6.1-beta.13_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime；包内不含 PaddleOCR、Tesseract、Whisper 或语音模型。
