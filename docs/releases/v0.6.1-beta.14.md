# SelfAnalyst v0.6.1-beta.14

这是接续 v0.6.1-beta.13 的预发布版本，交付知识页 UX 优化第一期。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- **页头与过滤**：通过“新建”菜单创建项目/主题；“重新自动匹配”移入“更多”，确认影响后执行。名称搜索在停止输入约 300 ms 后自动刷新，回车立即查询。“待整理”直接筛选未归类或歧义活动，时间范围提供全部、近 7 天、近 30 天和自定义。
- **详情与关系**：先展示类型、名称、来源只读标记、说明和别名；编辑与添加关系保留为主要操作，合并/删除收进“更多”，删除使用应用内确认。关系按对端类型分组并注明本页数量，分别使用图标和短标签展示已确认、自动推测、自动记录、待确认。已确认关系不再重复提供确认按钮。
- **更清楚的状态**：来源正常时不显示覆盖说明；来源不可用或达到上限时显示警告。周期时间说明只保留一处按需提示，详情中的时间筛选可直接清除。确认或否定关系后恢复列表与详情滚动位置。
- **键盘与安全**：菜单支持方向键与 Esc；目标选择器改为带搜索、分页、活动选项提示的 ARIA 组合框，支持方向键和回车。保留文本安全渲染、过期请求丢弃及保存失败后输入保留、不重复提交的行为。中英文文案同步更新。

本轮仅调整前端，不修改后端接口、数据库格式、第三方依赖或采集边界。关系详情已提供 other.type，分组直接使用现有字段。分组数量仅表示当前页，关系总数仍由分页器显示；独立“待整理”收件箱、批量归类和实体统计不在本期范围。

## 验收范围与已知限制

知识页 PR #148 精确 head 6880415 的五项 CI 全部通过，包括 Windows 全量验证；新增的知识页行为/样式定向检查 28 项通过。版本准备以合并后的 main 55762027 为基线，后续版本 PR 与发布 tag 仍需各自通过远端门禁，不能复用旧 head 的结果。

本轮未完成 Tauri 人工视觉验收：云端缺少 Cargo，Chromium 也受运行环境 socket 限制；用户已同意不附截图、不修改 workflow。保留的 scripts/check-knowledge-ui.py 仅完成静态检查，没有把其尚未执行的浏览器断言写成通过。现有共享主题只有浅色定义，深色系统偏好不会自动生成深色页面。

版本 PR 和发布 tag 的 Windows 自动化将执行 Java/Node、Rust/Clippy、UIA、JAR 冒烟以及安装包验证。所有打包在 GitHub Actions 远端执行，不本地打包。这份文件记录版本准备时的范围，发布页在完成后补充实际结果；自动化不替代人工视觉或真实账户端到端验收。

## 隐私、兼容与升级

继续保留 beta.13 的应用隐私设置与 ChatGPT 续聊修复。“仅对模型隐藏”仍不是完全隔离：数值 AQL 聚合和结果元数据可能包含隐藏事件的时长或数量；规则不撤回已发出的请求，也不改写已有摘要和会话。文件采集仍只收集显式配置目录内的文件系统元数据，除安全解析 .gitignore 外不读取普通文件正文；不持久化 UIA 正文、截图或音频。

ChatGPT 连接继续使用 OpenAI Sign in with ChatGPT 开源客户端预览，订阅不等于 API 额度，也不保证预览资格或直接模型访问；API Key 与 ChatGPT 连接独立。完整 OAuth、切换账户、刷新和断开的真实账户验收仍未全部完成，本轮未重跑真实账户调用。

升级前通过托盘完全退出旧版，备份完整运行数据根、配置和配置到根外的事件、记忆与索引目录。不要让不同版本同时使用同一数据或凭据目录，建议先使用独立测试数据目录。

继续沿用 Wiki schema 5。从 beta.7 或更早版本首次升级后，旧版不能直接打开升级后的 Wiki 数据库；自动 Wiki 备份不替代完整备份，不要手工修改 SQLite user_version。beta.11 已引入凭据刷新锁与轮换后身份校验，不要将新版凭据复制回 beta.10 或更早版本。凭据文件仅由当前用户权限保护、未做应用层加密，备份可能包含凭据，须保护访问权限。

回退时先在新版断开 ChatGPT 账户并核对远端撤销，完全退出后保留当前数据副本，将兼容的升级前完整备份恢复到隔离目录并重新授权；恢复会丢失备份后新增数据，旧 refresh token 不保证有效。卸载或恢复数据不等于撤销 OpenAI 授权，回退也不会保留新版新增的隐私保护。

## 安装与分发包

完成备份并退出旧版后，下载安装包，或将便携 ZIP 解压到新目录并运行 SelfAnalyst.exe。默认使用当前用户应用数据目录；主动添加 portable.marker 后才使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。

发布门禁与资产校验通过后提供：

- SelfAnalyst-portable.zip：自带 Java 21 runtime 的免安装包，包含 OAuth 回环回调所需的 jdk.httpserver。
- SelfAnalyst_0.6.1-beta.14_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime；包内不含 PaddleOCR、Tesseract、Whisper 或语音模型。
