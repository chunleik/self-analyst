# v0.6.1-beta.16

本版本为预发布（Pre-release），不替换最新稳定版。通过现有 GitHub Actions 远端构建便携 ZIP、NSIS 安装包和 SHA-256；本文不是发布成功或附件就绪的证明。

## 改进

- 增强消息面和备用消息面共用一个多行自适应输入框，Enter 发送、Shift+Enter 换行，增加中文 IME 组合保护。
- 图片选择、粘贴、拖放、缩略图与移除集中在输入区，保持 PNG/JPEG、最多 4 张、单张 5 MiB、总计 20 MiB、单张 2000 万像素限制。
- 保留流式回复、原轮次停止与失败重试；明确区分准备和生成阶段，保护会话切换与异步图片解码期间的草稿。
- 改进键盘、非颜色状态和中英文提示。主窗口让网页接收文件拖放，未增加文件系统读取权限。
