# v0.6.1-beta.17

本版本为预发布（Pre-release），不替换最新稳定版。分发包仅通过现有 GitHub Actions 远端构建；本文不是发布成功或附件就绪的证明。

## 改进

- 配置的连接页新增明确的“删除连接”按钮，区分未保存草稿与已保存连接，删除前确认目标；保留其他编辑，遇到版本冲突或未知结果时阻止误写，披露凭据清理待处理状态。
- 新增 MCP 工具弹窗，展示已发现 tools 的名称、描述、参数 schema 与批准状态，支持中英文、键盘焦点、Escape 与小尺寸窗口。查看和发现不代表授权或执行，不枚举 resources/prompts。
- 新增独立的开发者 Langfuse 观测设置，可选择自己的本地、局域网或远程服务器；默认关闭、默认元数据，保存与合成测试不会自动启用。
- 私密文本须另行选择类别、来源、会话/运行范围并确认完整接收地址、项目、IP 与 CA；授权仅限本次运行。后续调用可能包含先前上下文，不会独立扫描或补传历史记录。图片/附件内容当前不支持，未知混合来源保守省略。
- 使用系统安全凭据存储、非回环 HTTPS、实际 DNS/IP 绑定、有限异步队列与重试；停止、换目标或改来源使相应授权失效，不放宽既有模型、邮箱和 MCP 权限。
- OTLP 仅将合法 HTTP 200/JSON 响应计为协议接受，区分部分拒绝和安全警告；协议接受不等于 Langfuse 已入库或索引。停用本地导出不能撤回远端副本。
