# v0.6.1-beta.18

本版本为 Windows beta 预发布版，不替代最新正式版。

## 邮箱目录与安全配置

- 新建邮箱默认允许当前及未来新增的全部可读文件夹；也可切换为指定文件夹范围，最多 256 项。全部范围不等于自动下载或后台同步。
- 保存连接配置后，有可用凭据时自动加载文件夹；新账户可输入临时授权码连接并加载，搜索完整目录名称、勾选、选中当前全部或清空。指定范围不会自动包含未来新增目录。
- 刷新失败保留旧列表并标记过期；已选但暂未发现的目录不会自动移除。保存或启用成功与目录加载失败分别提示，避免重复保存或误报失败。
- 邮箱不再显示独立启用、凭据保存和原处理授权三个勾选项。确认账户、范围、模型目标及留存说明后，凭据写入并核验 Windows 系统凭据库，再启用邮箱；不支持安全存储时不降级为明文或会话保存。
- 正文许可仍独立选择。管理端发现仅列举目录，不读取邮件、不启用账户，也不把目录交给模型或开发者观测。取消、切换、删除和断开会使过期结果失效。

## 兼容性与验证边界

本次按尚无旧邮箱用户的前提设计，不提供旧邮箱配置迁移；缺少显式文件夹范围的旧格式会报错，不自动扩大权限或改写原文件。

合成协议、单元与浏览器测试不能代替真实 QQ/163 联调或 Windows/Tauri 人工验收。服务商决定可见目录与历史邮件范围；软件不发送邮件、不改变已读状态、不下载附件。断开不删除会话历史、备份或远端邮件，也不撤回已发送给模型的数据。

本版本通过 GitHub 远端工作流构建。发布完成后请使用 Release 中的安装包或便携 ZIP，并核对对应 SHA-256 文件。
