# SelfAnalyst v0.6.1-beta.19

本次预发布包含 PR #160 的邮箱设置与会话输入框改进。

## 变化

- 邮箱连接固定使用全部可访问文件夹，包括自定义文件夹和之后新增的文件夹；移除文件夹范围开关、选择器和自动发现界面。此版本不迁移旧的指定文件夹配置；遇到非全部范围配置会明确拒绝，避免静默扩大授权。
- 保留读取正文授权、模型目标确认和加密凭据激活流程；全部文件夹可访问不等于后台自动下载或批量读取所有邮件。
- 移除会话输入区多余的内层聚焦线，保留外层聚焦反馈；移除“图片要求”提示面板。
- 粘贴图片后，预览直接显示在输入框上方；没有图片时不占位。图片限制、错误提示、移除操作及会话隔离继续保留。
- 补充邮箱返回配置的范围校验和对应回归测试；增加远端 CI 输入框截图验证。

## 验证与边界

- 功能 PR #160 最新提交的五项必需 CI 检查通过，包括 Windows 全量验证；合并提交为 `6538be12f1a2d3c26ac6ca44d1e25267779ffe79`。
- 功能阶段全量 Node 测试共 493 项，461 通过、32 平台相关跳过、0 失败。远端 Linux 输入框与邮箱截图已核查。
- 尚未使用真实 QQ/163 账号执行端到端邮箱验收；自动化 CI 与 Linux 浏览器截图不代替 Windows/Tauri 中真实输入法、系统剪贴板及真实邮箱的人工验收。
- 此版本准备不在本地打包。版本 PR 的远端检查和发布标签触发的 Windows 产物校验必须完成后才可交付安装包。

## 发布通道

此版本为 Pre-release，不替代 latest 正式版。Windows 发布工作流提供 NSIS 安装包、便携 ZIP 与 SHA256 校验文件；下载后应对照对应校验文件核验。
