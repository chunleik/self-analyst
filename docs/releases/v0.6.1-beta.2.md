# SelfAnalyst v0.6.1-beta.2

这是接续 v0.6.1-beta.1 的预发布版本，新增可配置的 Neo4j 手工同步，供需要外部图查询的用户试用。它不替代 v0.6.0 稳定版；应用内「检查更新」只查询最新稳定版，不会提示安装本版本，请从本预发布的 GitHub Release 页面手动下载。

## 更新内容

相对 [v0.6.1-beta.1](v0.6.1-beta.1.md)：

- 新增默认关闭的 Neo4j 图快照同步。「知识」页面可查看目标、数据范围、状态和覆盖说明，每次发送前都需要确认；保存配置、启动、刷新状态、重建本体和聊天不会连接 Neo4j。
- 同步当前有效、已应用用户纠错的实体、别名、合并身份、关系及证据；保留候选状态和推断性质，Neo4j 仅作为可重建投影，本地 SQLite、memory.json 和 Lucene 继续是权威数据。
- 密码只从应用进程继承的指定环境变量读取。仅接受环回 bolt 直连或经受信任 CA 验证的远端 TLS，不接受 URI 内嵌密码或跳过证书验证的地址。
- 使用独占命名空间与原子快照更新；重复同步不产生副本，清理过期应用投影时保留无关节点、其他命名空间和外部关系。同步设有容量限制、总网络超时与有界清理。
- 增加中英文桌面提示、配置与只读 Cypher 示例，并精简双语 README。

详见[Neo4j 配置、隐私与查询指南](../neo4j-sync.md)及[个人知识指南](../personal-ontology.md)。本次不增加模型调用，不迁移原始事件、Wiki 数据库或向量索引；同步也不能代替本地备份。

## 试用与升级

1. 使用托盘菜单完全退出旧版，并备份整个用户数据目录，包括 memory 目录中的 ontology.db。不要让稳定版和预发布版同时使用同一数据目录。
2. 下载本版本的 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。无需使用 Neo4j 的用户可保持默认关闭，原有本地功能继续可用。
3. 如需试用同步，先自行准备可信的 Neo4j 服务和账号，在启动应用前设置密码环境变量，再按指南填写高级配置。为每个独立本地数据集选择独占 namespace；共享命名空间会让后一次快照替换前一份应用投影。
4. 在「知识 → Neo4j 手工同步」中核对实际地址、数据库、命名空间和发送范围后确认。实体名称、描述、私密标题及证据文本可能被发送，目标服务及管理员可以访问；只向你信任且有权发送数据的目标同步。
5. 关闭同步或更换目标不会删除旧目标副本；本地纠错或删除也要等下次成功手工同步才反映到远端。提交附近超时可能意味着结果不明，请先检查同步元信息、等待连接清理，再手工重试。

默认使用当前用户的应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。本版本不要求手动迁移本地数据；回退前再次备份试用期间的数据。预发布版可能仍有问题，建议先用独立测试数据与命名空间验证。

## 分发包

- SelfAnalyst-portable.zip：Windows 免安装包，自带 Java runtime。
- SelfAnalyst_0.6.1-beta.2_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应的 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不安装 Neo4j 服务，也不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
