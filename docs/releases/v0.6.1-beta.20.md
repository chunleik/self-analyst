# SelfAnalyst v0.6.1-beta.20

## MCP 与邮箱

- 顶栏新增 MCP 管理页，统一连接、工具批准、显式诊断与删除。外部连接支持 Streamable HTTP、受限旧版 HTTPS SSE 和显式启动的本机 stdio。
- 内置邮箱可按账号选择是否向同一台电脑的原生 MCP 客户端开放。默认关闭，对外令牌与桌面、IMAP 和 SMTP 凭据隔离并加密保存。
- 增加远端草稿和 SMTP 发信。均默认关闭，先核对确切收件人及正文并逐次批准；发信需要独立 SMTP 授权码。确认丢失时先核对服务器，不自动重发。
- 固定服务商预设包括 QQ、163、126 和符合资格的个人 Gmail 应用专用密码。企业邮箱、Exchange Online、OAuth 和自定义邮箱服务器不在本次范围。
- 退役旧 `websearch.*` 活跃配置，不读取或迁移旧密钥。请在 MCP 页显式添加并启用默认停用的 Parallel Search 预设或通用搜索服务。

## 验证边界

邮件和 MCP 用合成账号、协议与回环测试验证。未登录个人真实邮箱、未发送真实邮件，也未验证所有客户端和服务商的互操作。Windows 安装包和校验文件由 GitHub Actions 发布。
