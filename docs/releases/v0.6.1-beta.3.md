# SelfAnalyst v0.6.1-beta.3

这是接续 v0.6.1-beta.2 的预发布版本，将 Neo4j 手工同步集中到配置窗口，并改善切换和重开面板时的状态保护。它不替代 v0.6.0 稳定版；应用内「检查更新」只查询最新稳定版，不会提示安装本版本，请从本预发布的 GitHub Release 页面手动下载。

## 更新内容

相对 [v0.6.1-beta.2](v0.6.1-beta.2.md)：

- 将完整 Neo4j 手工同步卡片从「知识」页移至「配置 → Neo4j 同步」独立页签，集中展示目标、发送范围、覆盖信息、隐私提示和同步状态。
- 保留默认关闭和逐次确认；「配置 Neo4j」可进入高级配置并定位相关字段，「刷新本地状态」只读取本地状态，不连接 Neo4j。
- 改善关闭、切换与重新打开配置窗口时的异步保护：放弃发送前检查后不会再弹出过期确认或发送；已经确认的同步仍保留防重复提交保护，重新进入不会自动重发。
- 保存高级配置后重新进入同步页签会读取当前已保存的目标；未保存草稿继续受离开确认保护。
- 更新中英文界面入口、README、使用指南及回归测试，并修正指南引言中遗漏的旧入口说明。

本次不改变后端 API、配置格式、同步数据范围或本地数据格式，也不新增模型调用。Neo4j 继续是可重建投影，本地数据仍是权威来源。配置、隐私与查询方法详见 [Neo4j 同步指南](../neo4j-sync.md)。

## 试用与升级

1. 使用托盘菜单完全退出旧版，并备份整个用户数据目录，包括 memory 目录中的 ontology.db。不要让稳定版和预发布版同时使用同一数据目录。
2. 下载本版本 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。原有 Neo4j 配置可继续使用，无需迁移；不需要 Neo4j 的用户可保持默认关闭。
3. 打开「配置 → Neo4j 同步」检查目标和状态；试用关闭、切换、重新打开及保存高级配置后的显示。尚未确认的发送前检查会随离开而失效；关闭面板不会取消已经确认并发出的同步请求。
4. 如需实际同步，每次先核对地址、数据库、独占命名空间及发送范围再确认。实体名称、描述、私密标题及证据文本可能被发送，目标服务及管理员可以访问；只向你信任且有权发送数据的目标同步。
5. 每个独立本地数据集使用独占 namespace。关闭同步或更换目标不会删除旧副本；本地修改需等下次成功手工同步才反映到远端。提交附近超时可能意味着结果不明，请按指南检查状态后再手工重试。

默认使用当前用户的应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。本版本不要求手动迁移本地数据；回退前再次备份试用期间的数据。预发布版可能仍有问题，建议先用独立测试数据与命名空间验证。

## 分发包

- SelfAnalyst-portable.zip：Windows 免安装包，自带 Java runtime。
- SelfAnalyst_0.6.1-beta.3_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应的 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不安装 Neo4j 服务，也不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
