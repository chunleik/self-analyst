# SelfAnalyst v0.6.1-beta.4

这是接续 v0.6.1-beta.3 的预发布版本，让看板时间轴直接阅读已有的完整概览，并在展开后按保存顺序显示各主题的完整标题与叙述。它不替代 v0.6.0 稳定版；应用内「检查更新」只查询最新稳定版，不会提示安装本版本，请从本预发布的 GitHub Release 页面手动下载。

## 更新内容

相对 [v0.6.1-beta.3](v0.6.1-beta.3.md)：

- 看板时间轴在默认状态下直接展示已有的完整文字概览，不再把概览留在折叠详情里，也不再用行数限制、截断或省略号代替；主题标题改到概览下方，作为次级信息。标题与概览相同时只显示一次。
- 没有文字概览时，仍按原来的标题和本地事实降级显示，不会生成或补写概览。
- 展开条目后，按已保存顺序显示各主题的完整标题与叙述。空的、缺失或格式不正确的主题字段不会挡住其他内容；标题或叙述中的特殊字符按文本显示。
- 证据为空数组、空对象、空白文本或缺失时隐藏证据区块，不再显示空的证据标签。非空证据、建议、生成状态、时段顺序和继续追问保持可用。
- 更新中英文 README 的活动回顾说明，并补充看板展示与主题透传的回归测试。

本次不改变模型、提示词、摘要生成、采集范围或本地数据格式，只把已经保存的概览和主题显示出来。旧摘要无需重新生成。时间轴口径仍见[活动统计说明](../activity-statistics.md)。

## 试用与升级

1. 使用托盘菜单完全退出旧版，并备份整个用户数据目录。不要让稳定版和预发布版同时使用同一数据目录。
2. 下载本版本 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。不需要迁移本地数据；已有摘要可直接查看。
3. 打开看板，确认已有概览无需展开即可完整阅读，主题标题在其下方。展开条目后，按原顺序阅读各主题的完整标题与叙述；空证据不再显示空标签。长文本应自然换行。
4. 没有概览的旧条目应保持原来的标题和本地事实展示。继续追问仍可带着条目上下文进行。
5. 预发布版可能仍有问题，建议先用独立测试数据验证。遇到问题请保留复现步骤，回退前再次备份试用期间的数据。

默认使用当前用户的应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。本版本不要求手动迁移本地数据。

## 分发包

- SelfAnalyst-portable.zip：Windows 免安装包，自带 Java runtime。
- SelfAnalyst_0.6.1-beta.4_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应的 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不安装 Neo4j 服务，也不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
