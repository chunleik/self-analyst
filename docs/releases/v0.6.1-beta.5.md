# SelfAnalyst v0.6.1-beta.5

这是接续 v0.6.1-beta.4 的预发布版本，修复看板时间轴上下摘要样式不一致，以及展开详情被自动刷新收起的问题。不替代 v0.6.0 稳定版；应用内「检查更新」仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- 当前/今天的本地降级摘要与历史概览统一字号、字重、行高、颜色及完整换行。
- 已展开条目在自动刷新、摘要内容更新和列表重排后保持展开，主动点击才收起；主动收起后，刷新也不会重新展开。
- 按稳定条目标识保存阅读状态，移除条目时清理。统计日期或时区切换时隔离状态，按本地时间 04:00 的统计日边界处理，并兼容夏令时与固定偏移时区。
- 保留完整概览、已保存主题明细、旧数据降级、安全转义及继续追问；不更改采集范围、模型、摘要生成或本地数据格式。

对应修复：[PR #114](https://github.com/chunleik/self-analyst/pull/114)。

## 验证与已知限制

修复针对性 Node 测试 34/34 通过，完整桌面 Node 测试 224 通过、31 个平台用例在本地跳过。修复 PR 的 Windows 全量验证和 macOS/Windows/Ubuntu 数据守卫已通过；本版本还须经过发布工作流的质量门禁与打包验证。

真实浏览器的 800×600 与桌面宽度视觉验收仍未完成，当前执行环境无法启动 Chromium；自动化 DOM/CSS 测试不代表人工视觉验收。此限制不应被理解为已经验证全部显示效果。

## 试用与升级

1. 使用托盘菜单完全退出旧版，备份整个用户数据目录。不要让稳定版和预发布版同时使用同一数据目录。
2. 下载 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。无需迁移本地数据或重新生成摘要。
3. 在看板展开一个历史条目，保持阅读超过多个 30 秒刷新周期，确认不会自动收起；主动点击收起后，等待刷新也应保持收起。
4. 检查当前/今天与历史概览的文字样式、长文本换行及继续追问。预发布版仍可能存在问题，建议先使用独立测试数据验证；回退前再次备份试用期间的数据。

默认使用当前用户应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。
