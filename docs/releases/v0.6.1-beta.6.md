# SelfAnalyst v0.6.1-beta.6

这是接续 v0.6.1-beta.5 的预发布版本，在帮助菜单中加入项目官网和知识相关文档入口。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- 新增“项目官网”，打开 [GitHub 仓库首页](https://github.com/chunleik/self-analyst)。
- 新增“帮助文档”，打开 [文档索引](https://github.com/chunleik/self-analyst/blob/main/docs/README.md)。
- 新增“个人知识指南”，打开 [个人知识与本体指南](https://github.com/chunleik/self-analyst/blob/main/docs/personal-ontology.md)，包括开始使用、关系与证据、纠错、备份与重建、聊天查询，以及 Neo4j 同步指南链接。
- 菜单提供中英文文案，并将文档、反馈/更新、官网/关于分组。文档目前为中文，英文菜单同样打开现有指南。
- Tauri 桌面版点击后使用系统默认浏览器，Web 版使用独立标签页；保留应用当前页面与未发送草稿，不附加本地活动数据或凭据。
- 可检测的打开失败显示本地化提示与固定链接；桌面重试继续走安全原生外链路径，关闭提示后，延迟失败不会重新打开提示或覆盖新信息。
- 本次不增加依赖、任意 URL 权限或采集范围，不改变模型、摘要、本地数据格式和稳定版更新通道。

对应功能：[PR #116](https://github.com/chunleik/self-analyst/pull/116)。

## 验证与已知限制

帮助专项 Node 测试 21/21 通过，本地完整桌面 Node 测试 229 通过、31 个 Windows 专用用例按平台跳过。PR #116 最新提交的 Windows 全量验证（包括 Java/Node、Rust 测试与 Clippy、UIA 冒烟及打包 JAR 冒烟）和 Windows/macOS/Ubuntu 数据守卫均已通过；版本准备 PR 和发布工作流仍各自执行质量门禁。

Windows 实机中英文菜单视觉检查及实际拉起系统默认浏览器尚未完成人工验收。自动化测试不代表已经验证全部显示效果和每台机器的浏览器配置。

## 试用与升级

1. 通过托盘完全退出旧版，并备份整个用户数据目录；不要让稳定版和预发布版同时使用同一数据目录。
2. 下载 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。本次无需迁移数据或重新生成摘要。
3. 打开“帮助”，分别点击“帮助文档”“个人知识指南”“项目官网”，确认系统默认浏览器打开对应页面，软件内当前页面及未发送草稿仍然保留。
4. 如遇问题，请保留复现步骤。建议先使用独立测试数据验证，回退前再次备份试用期间的数据。

默认使用当前用户应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。

## 分发包

- SelfAnalyst-portable.zip：Windows 免安装包，自带 Java runtime。
- SelfAnalyst_0.6.1-beta.6_x64-setup.exe：Windows 用户级 NSIS 安装包。
- 两份对应 .sha256 文件：下载校验和。

完整桌面体验面向 Windows 10/11，使用系统 WebView2 Runtime。发布包不安装 Neo4j 服务，不包含 PaddleOCR、Tesseract、Whisper 或语音模型。
