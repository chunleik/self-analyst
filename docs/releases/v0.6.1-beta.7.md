# SelfAnalyst v0.6.1-beta.7

这是接续 v0.6.1-beta.6 的预发布版本。当日或半天摘要仍在等待其他时段时，看板会完整展示已经完成的子时段摘要，并标明这是部分结果；展开后可以看到未完成时段、失败原因、用量和重试时间。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 更新内容

- 已结束的日或半天摘要在等待下级时，默认按时间顺序完整展示互不重叠的已完成子摘要原文和对应范围，并标注“部分摘要”。已完成的半天优先于其下属小时，避免把同一段活动重复展示。
- 折叠状态同时说明当前阻塞：等待生成、等待下级、失败、跳过、缺失或历史摘要不可用。展开后可查看未完成时段、失败原因、该下级已保存的调用与 token 额度，以及下次重试时间。下级消耗不会显示成父时段自己的消耗。
- 没有可用子摘要时标注“仅应用统计”，不再把仍在等待的日条目标成已经完成的主题总结。
- 完整父摘要就绪后自动替换部分结果。页面读取不触发历史模型调用，不改写已有 Wiki 状态，也不放宽质量校验、预算、层级依赖或重试规则。
- 展示不包含完整提示词、失败响应、配置或私密字段。旧数据缺少生成元数据时仍给出可读说明；标题、叙述和错误文案中的特殊字符按文本显示。

本次不增加依赖，不改变模型、采集范围、本地数据格式或稳定版更新通道。导致个别小时未通过质量校验的模型响应本身不在本版本修复范围内，已有摘要无需重新生成。

对应功能：[PR #118](https://github.com/chunleik/self-analyst/pull/118)。

## 验证与已知限制

PR #118 的提交树与合入 main 的 `0a35211` 一致。该 PR 最新提交的 Windows 全量验证（包括 Java/Node、Rust 测试与 Clippy、UIA 冒烟及打包 JAR 冒烟）和 Windows/macOS/Ubuntu 数据守卫均已通过；版本准备 PR 和发布工作流仍各自执行质量门禁。

看板预览使用合成数据。Windows 实机上的中英文菜单与部分摘要视觉检查尚未完成人工验收。自动化测试不代表已经验证全部显示效果。

## 试用与升级

1. 通过托盘完全退出旧版，并备份整个用户数据目录；不要让稳定版和预发布版同时使用同一数据目录。
2. 下载 NSIS 安装包，或解压便携 ZIP 后运行 SelfAnalyst.exe。本次无需迁移数据或重新生成摘要。
3. 打开仍在等待的历史日或半天条目，确认已完成子时段以“部分摘要”完整显示，并带有对应范围。展开后核对未完成时段、失败原因、用量和重试时间。没有子摘要时应显示“仅应用统计”。完整摘要生成后应替换部分结果。
4. 如遇问题，请保留复现步骤。建议先使用独立测试数据验证，回退前再次备份试用期间的数据。

默认使用当前用户应用数据目录；便携包添加 portable.marker 后使用程序旁数据目录。升级或卸载应用文件不会删除默认用户数据。
