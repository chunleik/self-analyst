# SelfAnalyst v0.6.1-beta.8

这是接续 v0.6.1-beta.7 的预发布版本，增加历史小时摘要的对话与本地修复。它不替代 v0.6.0 稳定版；应用内“检查更新”仍只查询稳定版，请从本预发布页面手动下载。

## 升级前必须备份

本版将 Wiki 数据库从 schema 4 升级至 5。旧版不能直接打开升级后的数据库；没有可恢复的升级前备份时，不应尝试降级，也不要手工修改 SQLite `user_version`。

升级前请通过托盘完全退出旧版，备份完整运行数据根、配置文件和所有配置到运行数据根之外的数据目录（包括事件、记忆和索引目录）。不要让稳定版和预发布版同时使用同一数据目录。新版会先创建并核验 `llm-wiki.db.before-summary-repair-v5.bak`，再进行事务迁移；备份损坏、过期不匹配或迁移失败时拒绝继续，保留原数据。自动 Wiki 备份只覆盖 Wiki，不能代替整个应用的备份。

## 更新内容

- 已结束且因质量校验失败的小时，在对应条目或父摘要失败依赖旁提供“对话修复”，绑定准确时间范围与目标版本。普通追问继续保留。
- 修订卡提供整体摘要、主题和任务片段编辑；用户补充内容须逐项确认准确文字，经完整本地质量校验后明确保存。聊天或模型回复不会自动发布摘要。
- 用户确认内容持续标记为自述来源，最高 medium 置信度，不伪装成自动采集事实。保存保留原始活动、活跃/AFK/应用统计以及已经产生的模型调用与 token 用量。
- 无模型、模型不可用或预算耗尽时，仍可从空草稿本地编辑、确认、校验和保存有效修订；这些本地操作本身不调用模型。模型辅助修复沿用原目标小时的累计调用/token 预算及既有全局准入预算；重复请求、取消或重启不会清零该小时的历史消耗。
- 支持草稿持久恢复、并发冲突提示、显式应用草稿到最新失败记录，以及幂等保存。修复后父摘要按正常调度重新评估；其他失败依赖或父级额度不足仍会阻塞。
- 看板隐藏“未识别应用活动”和“AFK 覆盖不足”固定诊断及重复提示，底层统计、真正的 AFK 技术主题、摘要失败原因和修复入口保留。
- 修复增强聊天面响应式重绘丢失修订卡的问题，并保护未发送输入和本地编辑状态；中英文及 fallback 界面保持同一修订流程。

对应功能：[PR #120](https://github.com/chunleik/self-analyst/pull/120)。操作及数据边界见[修复指南](https://github.com/chunleik/self-analyst/blob/v0.6.1-beta.8/docs/summary-repair.md)和[运行数据备份与回退](https://github.com/chunleik/self-analyst/blob/v0.6.1-beta.8/docs/runtime-storage.md#摘要修复存储升级与回退)。

## 安装、试用与回退

1. 完成上述退出与完整备份后，下载安装包，或将便携 ZIP 解压到新目录后运行 `SelfAnalyst.exe`。默认使用当前用户应用数据目录；添加 `portable.marker` 后使用程序旁数据目录。
2. 在测试数据或已备份数据上打开质量失败小时，核对准确时段，尝试本地编辑→逐项确认→校验→保存，并检查“用户修订”来源及父级阻塞原因。
3. 如需回退，先退出新版并另存当前完整数据，再把兼容的升级前完整备份恢复到隔离目录，显式用旧版打开该目录。不要仅把旧 Wiki 库覆盖到混有新版聊天/索引/事件状态的目录。
4. 恢复旧备份不包含备份后的活动、聊天和修订。请保留新版数据副本；无可用备份时保留新版，不承诺无损降级。

升级或卸载应用文件不会删除默认用户数据。
