# 运行数据目录

安装版与标准免安装 ZIP 默认使用 `%LOCALAPPDATA%\com.selfanalyst.desktop` 作为运行目录。默认配置位于其中的 `data/config/config.toml`，数据库、记忆等默认位于 `data/` 下，日志位于运行目录的 `logs/` 或后端日志文件中。程序版本和解压位置不会改变默认数据位置。

## 显式便携模式

退出应用，在免安装包的 `SelfAnalyst.exe` 同级创建空的普通文件 `portable.marker`，再启动即可使用程序旁的 `data/`。安装版始终使用用户目录，不受此标记影响。目录或标记不可用时启动失败，不静默切换数据位置。

标准包不预置用户配置、数据或便携标记。桌面设置下方显示当前模式、运行目录和数据目录；受管桌面可点击“打开数据目录”，浏览器仅显示路径。切换模式需要退出并重新启动。壳的引导诊断日志和系统临时握手文件仍可能位于用户或临时目录，便携模式不承诺完全不留系统痕迹。

直接使用 `java -jar` 时仍以调用者工作目录为运行目录，数据准入规则相同。

## 已有数据

本次不搬运数据，不自动查找其他目录中的旧 portable 数据。

- 安装版原用户目录的数据可继续使用。
- 要原地使用旧 portable 数据，在其 EXE 同级添加便携标记。
- 选定目录缺少格式标记时，程序先获取锁并只读检查既有配置、数据库、事件、索引、Agent 状态等结构。全部兼容后原地生成 `data/storage-format.json`，不转换业务格式。
- 格式未知、不兼容、损坏或不能只读确认时拒绝启动，保留原数据。已有格式标记损坏也不会被覆盖。
- 数据库仍有未处理的日志状态时，先正常关闭原版本，再尝试启动新版。不要手工伪造、删除或降低格式号以绕过检查。

## 同时运行与退出

遵循新协议的后端通过 Java 跨平台文件锁独占 `data/app.lock`。锁文件存在不表示应用仍在运行，不需要删除它。生产会话保守持锁至 JVM 退出，操作系统终止进程时释放锁，避免后台线程尚未停止时提前开放数据。

桌面壳原有单实例和窗口唤起行为保持不变。此锁无法约束未实现协议的旧版程序，旧版与新版不能同时使用同一数据。网络共享目录不在本次保证范围。若配置 `memory.dir`、事件或索引到数据根之外，不要让其他运行根共享这些可写目录；数据根锁不提供外置目录之间的互斥。

程序文件升级和卸载不删除默认用户数据。需要回退程序时先停止新版，使用已保留的旧版数据副本；不能假定旧程序理解新版数据格式。
