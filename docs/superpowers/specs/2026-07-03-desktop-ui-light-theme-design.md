# desktop-ui 浅色现代化主题设计

日期：2026-07-03

## 背景

`desktop-ui` 当前是无构建步骤的静态前端，入口位于 `self-analyst-app/src/main/resources/desktop-ui/`，主样式集中在 `styles.css`。现有界面为暗色主题，用户希望优化为更现代的浅色主题。

已确认的视觉方向为 A1「Airy Blue」：保留 A 方向的冷静工作台气质，但整体颜色更 light。页面使用接近白的冷灰蓝背景，卡片保持白色，边框为浅蓝灰，主交互使用中浅蓝。

## 目标

- 将 desktop-ui 从暗色主题改为浅色现代主题。
- 保持现有信息架构、布局、DOM ID、JS 行为和后端 API 不变。
- 让导航、卡片、按钮、表单、聊天、配置弹窗、状态标签和任务列表在浅色主题下保持统一层次。
- 保持桌面工具属性：清爽、可扫描、适合长期使用，不做营销页或强装饰视觉。

## 非目标

- 不新增主题切换功能。
- 不引入框架、构建步骤、图标库或外部资源。
- 不重构 `desktop-ui` 的 JS 模块。
- 不改变 `Agent` tab、`会话` tab、配置弹窗或聊天抽屉的行为。

## 设计

### 主题变量

在 `styles.css` 的 `:root` 中替换暗色变量为浅色变量：

- `--bg-primary`: 近白冷灰蓝背景，用于页面主背景。
- `--bg-secondary`: 白色或近白，用于顶部导航、侧栏、弹窗面板。
- `--bg-card`: 白色，用于卡片和面板。
- `--bg-card-hover`: 极浅蓝灰，用于列表 hover。
- `--bg-input`: 极浅蓝灰输入背景。
- `--border-color`: 浅蓝灰边框。
- `--text-primary`: 深蓝灰文本。
- `--text-secondary` / `--text-muted`: 中性蓝灰辅助文本。
- `--accent`: A1 中浅蓝，作为主按钮、激活 tab、焦点边框和链接色。

状态色继续保留绿色、橙色、红色语义，但改为更适合浅色背景的色值和淡色底。

### 组件风格

顶部导航使用白色背景、浅边框和轻微阴影。Tab 的 hover 态为浅蓝灰，active 态为浅蓝底加蓝色文字。

卡片保持 6-8px 的克制圆角和浅边框。阴影只用于弹层、浮动操作条和需要层级的容器，主区域卡片主要依赖边框形成层次。

按钮采用浅色主题下的标准状态：

- 主按钮：浅蓝实底、白色文字。
- 次按钮：白底、浅边框、深灰蓝文字。
- 图标按钮：透明底，hover 时显示浅蓝灰背景。
- 危险和成功按钮使用语义色，但降低饱和度以适配浅色 UI。

表单输入、textarea、select 使用浅蓝灰背景、浅边框和清晰 focus 蓝色边框。配置原文编辑器保持等宽字体和足够对比度。

聊天区域保持三栏布局。用户消息使用主蓝色气泡，助手消息使用白色卡片和浅边框，错误和 pending 状态保留明确的语义提示。

### 布局和数据流

布局不改动。`index.html` 中现有结构继续使用：

- `#top-nav`
- `#tab-agent`
- `#tab-chat`
- 配置 modal
- 聊天 drawer
- 全局 error overlay

数据流不改动。所有 API 调用、状态对象、事件处理和 i18n 逻辑保持当前实现。

### 错误和降级状态

错误 overlay 从暗色遮罩改为浅色全屏状态，保留警示图标和重试按钮。加载占位、空状态、LLM 未配置提示使用浅色背景下可读的 muted 文本。

## 实现范围

主要文件：

- `self-analyst-app/src/main/resources/desktop-ui/styles.css`

可选文件：

- `self-analyst-app/src/main/resources/desktop-ui/index.html` 仅在需要移除硬编码 inline 样式或补充无行为 class 时修改。当前设计优先不修改。

## 验证

- 静态检查 `styles.css` 是否仍为有效 CSS。
- 用浏览器打开 `/desktop-ui/` 或本地静态页面，检查 Agent tab、会话 tab、配置 modal、聊天 drawer、错误 overlay 的浅色效果。
- 检查 1200x800 桌面窗口和小于 800px 宽度下没有文字重叠、按钮溢出或不可读状态。
- 若可运行后端，执行 Maven app 模块测试或至少确认静态资源可被打包。

## 风险

- 纯 CSS 主题替换可能暴露原有组件中对暗色背景的隐含假设。
- 某些动态生成内容可能使用现有 class 但没有专门浅色态，需要通过浏览器截图检查补齐。
- 过浅的边框会削弱复杂面板层次，因此 A1 保留清晰但低对比度的蓝灰边框。
