## Why

当前“关于”只显示版本号，用户无法确认正在使用的版本何时正式发布。需要显示与安装版本精确对应的发布时间，并避免把构建时间或其他版本的日期误当作发布时间。

## What Changes

- 桌面“关于”增加发布时间，按当前界面语言和用户本地时区显示。
- 复用现有应用内弹窗，先显示产品名称、桌面版本、Tauri 和后端地址，再异步取得精确版本的公开 GitHub Release 发布时间。
- 缓存经验证的公开时间；离线或获取失败时显示已有缓存或明确的不可用状态。开发构建显示开发版状态，不查询或伪造发布时间。
- Web 版保留原有不虚构桌面版本的行为。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-help`: 扩展 SPEC-HELP-ABOUT-001，约定精确版本发布时间、异步展示、失败与开发版行为。

## Impact

影响 Tauri 帮助操作、共享帮助弹窗、中英文资源、Node/Rust 回归测试及双语 README。不修改发布工作流，不新增运行依赖，不自动检查更新或下载。
