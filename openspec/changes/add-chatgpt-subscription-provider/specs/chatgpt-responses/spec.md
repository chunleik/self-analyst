## Purpose

定义 ChatGPT 登录连接在服务端授予权限时调用 Responses 协议的可观察行为，涵盖消息、图片、工具、流式输出、用量与模型发现，并保留 SelfAnalyst 的单次尝试、超时、隐私和配置失败隔离语义。

## ADDED Requirements

### Requirement: SPEC-CGRESP-001 Responses 请求与连接隔离
ChatGPT 连接 SHALL 使用服务端允许的 Responses 端点及当前 OAuth access token，不将令牌发送到用户可任意修改的 API Key Base URL。请求 SHALL 包含所选模型和既有受限业务输入，正确表达系统指令、用户/助手消息和已支持的图片输入，MUST NOT 发送客户端输出上限参数。不受协议支持的生成参数 SHALL 被省略或明确拒绝，MUST NOT 以未经确认的参数导致静默语义变化。服务端拒绝、超时和网络失败 SHALL 报告实际受限错误，不自动发送到其它 provider。

#### Scenario: 使用已连接账户生成
- **WHEN** 用户选择 ChatGPT 连接并启动模型工作
- **THEN** 请求使用 Responses 协议和该连接的令牌，不携带已有 API Key，不发送 max_tokens、max_completion_tokens 或 max_output_tokens

#### Scenario: 保存自定义 API Key 地址
- **WHEN** 已连接 ChatGPT 时用户编辑其它 API Key 连接地址
- **THEN** ChatGPT 令牌不会被发送到该地址，模型请求只使用对应认证方式允许的目标

#### Scenario: 续聊包含助手历史文本
- **WHEN** 下一轮请求包含此前的助手文本回答，或助手文本与函数调用混合出现
- **THEN** 助手文本以 Responses 的 output_text 表达，系统/开发者、用户及工具结果文本保持 input_text，原有内容和工具顺序保持不变，不因复用用户输入类型导致服务端拒绝

### Requirement: SPEC-CGRESP-002 流式文本与工具调用保真
Responses 适配 SHALL 将文本增量和最终结果转换为既有聊天事件，并将函数名称、调用标识、完整参数及工具结果保真传递给既有串行工具执行流程。跨 SSE 帧拆分的参数 SHALL 在完成后组装为单一有效调用，MUST NOT 重复执行同一完成调用。plain、摘要及压缩调用 SHALL 返回完整最终文本，即使上游通过 SSE 提供结果。错误、取消、不完整或缺少终止结果的流 MUST NOT 被报告为成功完成。

#### Scenario: 工具参数跨多个事件到达
- **WHEN** 服务端将一个函数调用的参数拆分为多个 SSE 增量
- **THEN** 适配器保留调用标识并组装完整参数，既有工具链执行一次，再将匹配的工具结果送回模型

#### Scenario: 摘要使用流式上游
- **WHEN** 摘要调用收到多个文本增量及有效完成事件
- **THEN** 调用方获得合并后的最终文本，不将 SSE 数据直接当作摘要，也不重复拼接完成事件中的文本

#### Scenario: 流提前结束
- **WHEN** 上游在有效完成事件前关闭连接或返回失败事件
- **THEN** 当前工作报告失败并释放连接，不将已收到的部分文本误报为完整成功

#### Scenario: 完整事件流省略媒体类型响应头
- **WHEN** 受信任 Responses 端点返回 HTTP 200 但未提供 Content-Type
- **THEN** 系统仅在正文通过有界 SSE 协议校验并收到有效完成事件时报告成功；显式错误媒体类型、普通 JSON、HTML、失败事件或截断正文均不得报告生成成功

#### Scenario: 工具续轮需要加密推理项
- **WHEN** 服务端完成结果包含工具续轮需要的不透明加密 reasoning 项
- **THEN** 系统在限制类型、形状及大小后保存该项供后续 Responses 请求原样回传，不把加密内容解码为可见思考、写入日志或作为普通回答显示

### Requirement: SPEC-CGRESP-003 用量、边界与单次尝试
Responses 对话模型 SHALL 遵循每次执行 45 秒超时及单次生成尝试；plain/summary 生成 SHALL 单次尝试并以调用方给定的超时为准，内部上限与 API Key 模式默认执行上限一致为 5 分钟，MUST NOT 以更短的固定期限截断调用方允许的生成。生成 SHALL 限制响应大小，并在取消后释放网络资源。存在有效 input/output usage 时 SHALL 传递真实用量；缺失时由既有确定性估算及至多一次记账路径处理。令牌刷新不得形成隐式生成重试，错误分类与诊断 MUST NOT 输出授权头、令牌或完整远端正文。

#### Scenario: 服务端提供用量
- **WHEN** 正常完成事件包含 input_tokens 与 output_tokens
- **THEN** 既有用量计量得到该数值并至多记录一次，不再叠加同次调用估算值

#### Scenario: 生成遭限流
- **WHEN** Responses 端点返回限流或服务端错误
- **THEN** 当前调用报告对应失败，不在一次预算准入内重发生成请求，不回退到 API Key

#### Scenario: 摘要调用使用较长超时
- **WHEN** 摘要或修复调用以超过 45 秒的超时请求 ChatGPT plain 生成，服务端在该超时内完成流式结果
- **THEN** 调用得到完整结果而不因对话模型的 45 秒期限失败；超过调用方超时时按既有超时失败并释放网络资源

### Requirement: SPEC-CGRESP-004 模型发现与最小测试
用户主动发现模型时，系统 SHALL 只查询当前 ChatGPT 连接实际允许的模型目录，返回去重的有效模型 ID；不支持或无权限时 SHALL 明确说明并保留手工输入，MUST NOT 把固定候选伪称为已获授权的服务端结果。最小测试 SHALL 使用固定短提示且不包含会话、标题事实、文件元数据或业务提示词，只有有效生成结果才能报告成功；两种操作 MUST NOT 保存模型草稿或切换当前运行连接。

#### Scenario: 无模型目录权限
- **WHEN** 当前账户的目录请求被拒绝或目标不支持目录
- **THEN** 显示目录不可用原因并保留手工模型输入，不据此推断模型生成一定不可用

#### Scenario: 最小生成测试
- **WHEN** 用户主动测试 ChatGPT 模型草稿
- **THEN** 仅固定短提示被发送，返回实际生成成功或受限错误，配置与现有工作保持不变

### Requirement: SPEC-CGRESP-005 账户用量暂停与显式恢复
服务端明确返回 ChatGPT 订阅用量耗尽或限流时，系统 SHALL 对该账户暂停本进程后续业务模型请求，并在受保护状态接口与模型设置中显示暂停状态；其它账户及 API Key 连接 SHALL 不受影响。暂停 SHALL 不触发自动生成重试或供应商回退。用户主动最小生成测试 SHALL 保持可用，只有实际测试生成成功才能清除此进程内暂停；进程重启可重置本地暂停，但 MUST NOT 被描述为恢复服务端额度。目录成功、保存配置和刷新页面 MUST NOT 被当作模型额度恢复证据。

#### Scenario: 后台工作遇到额度限制
- **WHEN** 某 ChatGPT 账户的模型请求收到已确认的订阅限额或限流错误
- **THEN** 该请求失败且该账户后续业务请求在本地停止，界面显示暂停，独立其它账户及 API Key 仍按原规则工作

#### Scenario: 用户测试暂停账户
- **WHEN** 用户主动测试已暂停账户，服务端返回有效生成结果
- **THEN** 测试成功并解除该账户的本进程暂停，后续业务工作可再次尝试；测试失败时仍保持暂停
