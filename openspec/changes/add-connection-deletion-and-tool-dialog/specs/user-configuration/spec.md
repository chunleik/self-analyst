## ADDED Requirements

### Requirement: SPEC-CFG-INTEGRATIONS-004 明确删除与草稿隔离
连接页 SHALL 提供“删除连接”，确认说明对象和影响。未保存连接 SHALL 仅从当前草稿删除；已保存连接 SHALL 通过定向删除提交，不自动保存其它草稿。成功后 SHALL 保留其它连接的未保存编辑；取消、冲突或失败 SHALL 不丢弃草稿。删除结果不明时 MUST 提示重新读取状态，在核实前禁止重复写入且不宣称成功；重新加载丢弃草稿 SHALL 再明确确认。

#### Scenario: 删除多个空草稿中的一个
- **WHEN** 用户确认删除所选新建空白条目
- **THEN** 仅移除该草稿，不发删除或保存请求，其它空草稿和已保存连接仍保留

#### Scenario: 删除时其它连接有编辑
- **WHEN** 用户确认删除已保存连接而另一个连接存在未保存编辑
- **THEN** 仅提交所选连接的删除，另一个连接的草稿仍未保存且不丢失

#### Scenario: 删除响应丢失
- **WHEN** 删除请求返回结果无法确认是否提交
- **THEN** 保留草稿并显示状态待确认，用户读取当前保存状态之前不重试删除或覆盖配置

### Requirement: SPEC-CFG-INTEGRATIONS-005 可访问工具弹窗
MCP 连接 SHALL 有明确的“查看 MCP 接口”入口。弹窗 SHALL 有可访问名称、连接身份、目录状态、关闭按钮和中文/英文文案，支持键盘进入、焦点限制、Escape 关闭及焦点返回；长 schema 和窄屏 SHALL 可滚动。远端名称和描述 MUST 作为文本显示，不执行 HTML。

#### Scenario: 键盘查看接口
- **WHEN** 用户通过键盘打开弹窗、浏览内容并按 Escape
- **THEN** 弹窗关闭且焦点回到触发入口，背景不可在弹窗打开时误操作

#### Scenario: 远端描述含 HTML
- **WHEN** MCP 名称、描述或 schema 包含 HTML 片段
- **THEN** 显示原始文本，不执行脚本或加载远端资源

### Requirement: SPEC-CFG-INTEGRATIONS-006 独立观测设置与准确状态
Langfuse SHALL 位于开发者功能，独立于 MCP 连接，提供自定义地址、项目、只写秘密、采样、元数据/分范围内容选择及保存/启用/合成测试/停用/凭据清理入口。中英文说明 SHALL 展示真实接收方、类别及来源、授权期限、图片未支持、保险库可用性和远端保留风险，说明内容可能省略及授权期限，并分别显示未启用、已启用、失败/丢弃及清理待处理。显示开发者设置、保存或测试 MUST NOT 自动授权持续内容发送。

#### Scenario: 仅保存观测配置
- **WHEN** 用户完成地址与凭据设置但未明确启用
- **THEN** 配置状态显示未启用，不产生业务观测上传，也不把测试成功作为自动启用

#### Scenario: 查看本地观测失败
- **WHEN** Langfuse 断开或认证失效
- **THEN** 界面显示安全的错误分类和丢弃计数，不显示秘密、正文或异常原文，聊天仍可继续
