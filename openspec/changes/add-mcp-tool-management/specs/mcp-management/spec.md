## Purpose

定义 SelfAnalyst 的通用 MCP 工具管理平台，涵盖多 MCP 服务（内置 Provider 与外部服务）的注册与凭据隔离、对内 Agent 热挂载与工具级权限控制、对外本地回环 Streamable HTTP MCP Server 暴露与鉴权，以及桌面端顶栏独立 MCP 管理页面。

## ADDED Requirements

### Requirement: SPEC-MCP-REG-001..005 统一服务注册与凭据隔离
系统 SHALL 支持通过统一注册表管理多个 MCP 服务实例，每条记录区分服务标识、展示名称、类型（内置邮箱 `BUILTIN_EMAIL` 及外部 `EXTERNAL_STREAMABLE_HTTP`、`EXTERNAL_SSE`、`EXTERNAL_STDIO`）、对内启用开关、对外暴露开关、单工具禁用列表和超时参数。服务非敏感定义 SHALL 原子持久化至运行数据目录下的独立配置文件，敏感凭据（包括密码、授权码、Bearer Token、敏感环境变量及对外 MCP 鉴权令牌）MUST 隔离存储于受当前用户文件权限保护的独立凭据文件中。普通配置接口、状态响应、错误诊断与日志 MUST NOT 输出任何明文凭据。

#### Scenario: 添加并持久化新的 MCP 服务
- **WHEN** 用户通过桌面 API 添加一个携带认证凭据的 MCP 服务
- **THEN** 服务定义原子写入独立注册表文件，敏感凭据原子写入受限凭据文件，查询响应仅返回凭据存在状态而不回显明文

#### Scenario: 读取受限凭据目录权限异常
- **WHEN** 凭据文件或其目录不符合当前用户权限约束或损坏
- **THEN** 系统拒绝加载或写入该凭据并返回受限诊断错误，不降级为不安全写入且不泄露凭据内容

### Requirement: SPEC-MCP-HOST-001..005 对内 Agent 热挂载与容错隔离
已开启对内启用的 MCP 服务 SHALL 在应用启动及配置变更时动态注册到 Agent 的串行 Toolkit 中，修改服务配置、启停服务或调整禁用工具 MUST 无需重启后端即可生效，且不得中断正在进行的对话轮次。多个服务并存时，注册到内部 Toolkit 的工具名称 SHALL 按服务标识隔离以避免重名冲突。单个 MCP 服务的连接、初始化或工具发现失败或超时 MUST 被隔离并记录到该服务状态中，MUST NOT 阻断应用启动、Agent 构造或其他健康服务的使用；失败或停用的外部连接及子进程 MUST 被关闭回收。

#### Scenario: 热启用与热停用 MCP 服务
- **WHEN** 用户在运行期间将某个健康 MCP 服务的对内开关由关闭切换为开启，随后再切换为关闭
- **THEN** 无需重启后端，开启后 Agent 在后续轮次可发现并调用该服务的允许工具，关闭后该服务的工具从 Toolkit 移除且资源被释放

#### Scenario: 单个外部 MCP 服务不可达
- **WHEN** 已启用的某个外部 MCP 端点连接失败或初始化超过有限超时
- **THEN** 该服务状态标记为错误并记录受限诊断，应用启动、本地工具及其他健康 MCP 服务继续正常工作

#### Scenario: 工具级禁用生效
- **WHEN** 用户将某服务下的特定工具加入禁用列表
- **THEN** 该工具不再暴露给 Agent Toolkit，且直接调用该工具的请求被拒绝

### Requirement: SPEC-MCP-SRV-001..006 对外本地 MCP Server 暴露与鉴权
系统 SHALL 在现有本地回环服务（仅限 `127.0.0.1`）上提供标准 Streamable HTTP MCP Server 能力，支持按服务隔离的端点 `/mcp/{serverId}` 以及汇总全部已对外暴露服务的聚合端点 `/mcp/all`。服务对外暴露默认关闭；仅显式开启对外暴露的内置服务 SHALL 可经由上述端点被外部 MCP 客户端发现和调用，外部引入的第三方 MCP 服务 MUST NOT 被二次转发暴露。对外 MCP 端点 MUST 校验独立持久化的 Bearer Token，未携带或携带错误令牌的请求 MUST 返回未授权错误；令牌支持在管理界面中显式轮换，轮换后旧令牌立即失效。

#### Scenario: 外部客户端携带有效令牌访问单服务端点
- **WHEN** 某内置 MCP 服务已开启对外暴露，外部 MCP 客户端携带有效 Bearer Token 向 `/mcp/{serverId}` 发起初始化、`tools/list` 与 `tools/call`
- **THEN** 服务端按 MCP 协议返回该服务未被禁用的工具列表并执行工具调用

#### Scenario: 外部客户端访问未鉴权或未对外暴露的服务
- **WHEN** 外部请求缺少或携带错误 Bearer Token，或目标服务未开启对外暴露
- **THEN** 服务端分别拒绝请求（401 未授权或 404/不可用），不泄露内部凭据或未暴露服务列表

#### Scenario: 轮换对外 MCP Bearer Token
- **WHEN** 用户在桌面端执行对外 MCP 令牌轮换
- **THEN** 系统生成并持久化新令牌，旧令牌对 `/mcp/**` 立即失效，新令牌生效

### Requirement: SPEC-MCP-UI-001..005 桌面端顶栏独立 MCP Tab 页
桌面端主导航顶栏 SHALL 提供独立的一级 `MCP` Tab 页（与看板、知识、会话并列），并完整提供中英文国际化文案。该页面 SHALL 展示：对外 MCP Server 接入信息条（监听端点、掩码令牌、复制与轮换操作及客户端配置 JSON 一键复制）、已添加 MCP 服务列表（含运行状态、对内/对外开关、连接测试、工具权限管理、编辑与删除），以及添加服务向导（内置邮箱预设、联网搜索预设与自定义外部 MCP）。执行连接测试 SHALL 为显式诊断操作，具有有限超时且不自动修改未保存的服务配置。

#### Scenario: 通过顶栏切换进入 MCP 管理页面
- **WHEN** 用户点击主导航顶栏的 `MCP` Tab
- **THEN** 界面切换展示 MCP 服务列表、对外 MCP 接入信息条及添加服务入口

#### Scenario: 测试单个 MCP 服务连接
- **WHEN** 用户在服务卡片或编辑表单中触发连接测试
- **THEN** 后端在有限超时内验证连通性与工具发现并返回状态及工具摘要，不将敏感凭据写入返回诊断或日志
