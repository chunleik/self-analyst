## Why

SelfAnalyst 目前通过仓库文档介绍产品，缺少面向普通用户的介绍和下载官网。新增简体中文与英文官网，让访问者快速理解产品用途、隐私边界和 Windows 安装方式。

## What Changes

- 新增静态官网，提供产品介绍、界面展示、核心功能、下载、快速开始、隐私说明与项目链接。
- 提供完整简体中文和英文内容、显式语言切换、首次浏览器语言选择及语言偏好记忆。
- 下载入口指向本仓库 GitHub Releases，说明 Windows 安装包和便携包的区别。
- 通过 GitHub Pages 和 GitHub Actions 发布，支持仓库子路径访问。
- 官网双语内容为用户明确要求的文档语言例外；规划和维护文档继续使用简体中文。
- 本次新增官网行为，不改变桌面应用、采集服务或模型调用行为。

## Capabilities

### New Capabilities
- `project-website`: 双语产品展示、下载引导、隐私说明及静态官网发布行为。

### Modified Capabilities

无。

## Impact

- 新增独立 `website/` 静态资源和官网发布工作流，不直接发布桌面 UI 或整个仓库。
- 更新必要的仓库官网入口和简体中文维护说明；新增官网主规格。
- 使用现有公开产品截图前检查敏感内容；下载复用 `chunleik/self-analyst` 的 Releases。
- 无新增后端、数据库或运行时服务依赖。实施交付遵循功能分支、PR 和最新提交必需检查流程。
