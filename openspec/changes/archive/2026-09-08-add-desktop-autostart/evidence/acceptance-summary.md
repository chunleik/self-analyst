## 对照实验与环境判断

普通手动启动与从系统工作目录执行 `--autostart` 的对照实验均完成单实例获取、Tauri 初始化、后端启动与健康检查，以及对应的窗口创建。这些实验用于定位问题，没有替代真实登录验收。

最初工具进程内的注册表读取结果与独立 Windows 注册表服务不一致。改由用户从 Windows 文件资源管理器独立启动并开启后，`StdRegProv` 和 `Win32_StartupCommand` 均确认系统可见入口，随后真实登录正反两种场景通过。后续验收需保留这一独立核对步骤。

原始运行日志和进程快照仅保留在本地临时目录；本文件记录可提交的验收结论。
