## Why

SelfAnalyst 目前需要用户手动启动，容易遗漏登录后的活动记录。增加可选择的登录自启动，并只驻留托盘，可以持续使用既有后台能力而不打断用户。

## What Changes

- 新增当前 Windows 用户登录后的自启动能力，默认关闭，由托盘“开机自启动”勾选项管理。
- 自动启动仅驻留托盘，不显示主窗口；后端继续遵循既有配置、认证和生命周期约定。
- 修改重复启动行为：自动重复启动静默退出，手动重复启动唤起已有窗口，不创建第二个后端。
- 支持安装版与便携版；安装版卸载清理所属启动项，便携版移动后由用户重新开启以更新路径。
- 系统启动项由桌面壳管理，操作失败明确反馈，不把启动项状态写入 Java 的 config.toml。

## Capabilities

### New Capabilities

无；在既有桌面壳能力中扩展。

### Modified Capabilities

- `desktop-shell`：增加自启动设置、静默启动与分发生命周期契约，调整托盘和窗口单实例行为。

## Impact

- 桌面壳 Rust 启动入口、窗口创建、托盘菜单、单实例通信及对应测试。
- Windows 当前用户启动项管理与 NSIS 安装、升级、卸载处理。
- 桌面壳主规格和用户文档；不新增 Java HTTP 配置接口，不改变采集范围。
- 实施时评估 Windows API 所需依赖特性；本提案不锁定新增第三方插件。
