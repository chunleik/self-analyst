## 验收中修复的问题

故障注入发现当前 Tauri Windows 运行时将请求的退出码转换为普通退出，导致后端故障仍以零码结束。桌面入口现保留 `ExitRequested` 中的退出码，在 `run_return` 结束后传给进程。完整便携冒烟重跑通过，损坏 JAR 场景作为该问题的回归检查。

另已避免使用与产品名相同的 Run 值：Tauri 默认卸载模板会无条件删除产品名对应入口，项目改用 `SelfAnalystDesktop`，由路径归属钩子管理。安装生命周期测试验证了卸载不误删其他分发入口。
