## Why

用户希望通过 Agent 将采集记录、统计结果和整理后的报告制作成实际文件，并保存到电脑上的其他目录。现有文本聊天、Wiki 摘要和事件导出基础尚未形成统一的 Agent 文档生成、会话成果管理和桌面另存为流程。

## What Changes

- 新增 Agent 文档工具，支持 CSV、JSON、Excel（`.xlsx`）、Word（`.docx`）、PDF、Markdown 和 PPT（`.pptx`）七种格式。
- 支持两种内容路径：后端按查询条件直接导出记录；Agent 将已有摘要、统计结果和用户输入组织成报告或演示文稿。大量记录不经模型逐条转写。
- 新增本地文档成果及不可变版本，关联生成它的会话与用户轮次；成功文件可在重启后再次保存，修改要求生成新版本。
- 会话展示服务端确认的文件卡片；桌面端通过系统“另存为”选择其他目录，浏览器端提供认证下载。
- 明确生成失败、取消、重试、大小限制、删除会话和保存失败的行为；用户已另存的副本由用户管理。
- 本次是新增功能与既有会话交互扩展，不是文档基线迁移。第一版不包含定时报告、任意本地文件读取、已有 Office 文件导入、通用脚本执行、在线编辑器或自定义模板上传。

## Capabilities

### New Capabilities

- `agent-document-generation`：文档工具、数据来源、格式支持、生成与版本生命周期、认证文件读取及资源边界。

### Modified Capabilities

- `agent-runtime`：注册文档工具并传递可信会话与轮次身份，复用既有串行执行、取消及预算行为。
- `chat-sessions`：持久化服务端文档关联，支持历史恢复、轮次重试和会话清理。
- `desktop-chat`：在增强消息面及降级消息面展示文件卡片、保存动作和失败状态。
- `desktop-shell`：提供受限的系统另存为流程，并支持浏览器认证下载。
- `raw-event-retention`：允许受管桌面聊天调用后端原始记录导出，但不向模型返回逐 heartbeat 正文，保留原始查询认证和范围限制。

## Impact

- Java：`self-analyst-app` 中 Agent、AppSession、桌面 API、会话存储和新增文档服务；复用 events 原始查询与投影查询、Wiki 和文件元数据查询边界。
- 桌面：`self-analyst-app/src/main/resources/desktop-ui/` 的会话渲染、API 调用和本地化；`self-analyst-desktop/src-tauri/` 的原生保存、权限配置及打包验证。
- 存储与 API：会话数据库新增文档元数据/关联，应用数据目录保存文档与生成源；新增带会话归属校验的文件元数据和内容读取接口。已有会话无文档时保持兼容。
- 依赖：需要 JVM Office/PDF 渲染实现、可分发中文字体与 Tauri 文件对话框支持；候选库、许可和打包方案在设计与实施验证中明确，不要求用户安装 Office、Python 或 Node 运行时。
- 验证：覆盖七格式可打开性、中文排版、原始记录准确性、认证、幂等恢复、原生另存为及安装/便携包运行；实施完成后同步相关主规格和中文用户文档。
