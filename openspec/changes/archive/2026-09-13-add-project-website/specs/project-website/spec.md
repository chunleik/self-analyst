## Purpose

定义 SelfAnalyst 面向公众的介绍和下载官网，使简体中文与英文访问者能够了解当前产品功能、数据边界、Windows 分发方式及首次使用步骤，并通过可靠的静态网站入口访问项目资源。

## ADDED Requirements

### Requirement: SPEC-WEB-001 产品介绍与使用引导
官网 SHALL 提供产品定位、真实界面展示、核心功能、Windows 下载、快速开始、隐私说明及源码、文档和问题反馈入口。官网 MUST 以当前产品能力为依据，明确应用需要在本机安装运行。

#### Scenario: 了解并开始使用产品
- **WHEN** 访问者打开官网
- **THEN** 能了解本地优先个人活动分析用途，并找到安装、模型配置和首次使用步骤以及项目资源入口

### Requirement: SPEC-WEB-002 双语选择
官网 SHALL 完整提供简体中文与英文的正文、导航、按钮、页面标题和可访问性文本。显式语言地址 SHALL 优先于已保存偏好；无显式语言地址时 SHALL 优先使用有效偏好，否则按浏览器首选语言选择，中文选择简体中文，其余语言回退英文。语言切换 SHALL 记住用户选择；存储不可用时 MUST 仍可浏览和切换。

#### Scenario: 首次访问
- **WHEN** 没有有效偏好且访问未指定语言的入口
- **THEN** 中文浏览器显示简体中文，英文或其他语言浏览器显示英文

#### Scenario: 切换及再次访问
- **WHEN** 用户选择另一种语言并再次打开未指定语言的入口
- **THEN** 在偏好存储可用时继续显示所选语言，内容和导航语言保持一致

#### Scenario: 直接访问与存储失败
- **WHEN** 用户直接访问一种语言的地址，或浏览器阻止偏好存储
- **THEN** 直接地址显示指定语言，且正文、下载入口与语言切换仍然可用

### Requirement: SPEC-WEB-003 下载入口
官网 SHALL 将下载操作引导至 `chunleik/self-analyst` 的 GitHub Releases，明确 Windows 安装包与便携包的使用区别，并提供全部版本入口。官网 MUST NOT 展示未经核实的版本号、文件名或其他平台下载承诺。

#### Scenario: 获取分发包
- **WHEN** 用户选择下载
- **THEN** 到达仓库正式版本入口，可依据官网说明选择安装包或便携包，并能访问全部版本

### Requirement: SPEC-WEB-004 准确的隐私说明
官网 SHALL 说明本地存储、仅持久化标题的内容采集、显式目录内文件元数据采集，以及配置联网模型等服务时所需输入可能外发的边界。官网 MUST NOT 宣称所有数据永不离开设备，也 MUST NOT 将截图、OCR、音频或文件正文采集描述为当前功能。官网自身 MUST NOT 连接本地桌面 API、收集应用数据或要求 API 密钥。

#### Scenario: 阅读数据边界
- **WHEN** 用户查看任一语言的隐私说明
- **THEN** 能区分本地采集存储与可选联网服务的数据发送，并可访问详细隐私文档

### Requirement: SPEC-WEB-005 静态发布与可访问性
官网 SHALL 能通过 GitHub Pages 在仓库子路径下提供完整内容，语言页面刷新、样式、图片和站内链接 SHALL 正常。网站 SHALL 适配移动端和桌面端，提供键盘可操作的导航、语言及下载入口、清晰焦点和有意义的图片替代文本。发布内容 MUST 限于官网公开资源。

#### Scenario: 子路径及窄屏访问
- **WHEN** 用户从项目 Pages 子路径直接打开语言页面并刷新，或使用窄屏与键盘浏览
- **THEN** 内容与资源正常加载，无阻碍阅读的横向溢出，主要入口可识别并操作

#### Scenario: 发布范围
- **WHEN** 发布官网
- **THEN** 只发布官网静态资源，不包含用户配置、数据库、日志或其他仓库内部文件
