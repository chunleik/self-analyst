## Why

当前免安装包默认把数据保存在程序旁边，换解压位置会产生新的数据集，删除程序目录也容易误删长期记录。需要将默认数据位置与程序版本解耦，并在多个版本共享目录时防止并发写入和不兼容格式访问。

## What Changes

- **BREAKING**：免安装桌面包默认使用当前用户应用数据目录，与安装版一致；只有显式便携标记才使用程序旁的数据。
- 保留程序资源与运行数据分离，配置仍位于所选工作目录的 `data/config/config.toml`，既有相对数据路径随工作目录解析。
- 新增 Java 标准库跨平台独占锁，在打开业务存储前获取并持有至存储关闭；占用或锁不可用时拒绝启动。
- 新增独立于应用版本的数据格式标记：新空目录初始化；选定目录已有数据但无标记时，取得独占锁并只读检查存储结构，确认与当前格式兼容后原地补标记并继续使用，不改变业务数据。
- 不自动发现、复制或迁移其他目录的旧 portable 数据。安装版已有数据及显式便携模式选中的旧数据均可按兼容检查原地接纳；未知、不兼容或损坏格式仍拒绝启动。
- 设置中展示当前运行模式、实际数据位置并提供打开目录入口；补充分发及用户说明。
- 不实现数据迁移、自动格式升级、备份恢复工具、分布式锁或新增桌面 OS 分发。

## Capabilities

### New Capabilities
- `runtime-storage`: 数据根独占、格式准入、生命周期顺序和可诊断失败。

### Modified Capabilities
- `desktop-shell`: 默认用户数据位置、显式便携模式、分发内容以及数据位置展示。
- `user-configuration`: 工作目录从便携包根改为运行根，保留 TOML 路径和配置优先级。

## Impact

- 桌面壳 `self-analyst-desktop/src-tauri/src/lib.rs` 的工作目录选择、启动失败反馈及目录打开命令；启动日志与临时握手文件需与业务数据准入协调。
- Java `App.java` 启动入口、存储初始化和关闭流程；增加启动守卫及独立进程测试，不引入本地平台专用锁依赖。
- 桌面设置 API/UI、`scripts/build-portable.ps1` 及相关安装/冒烟脚本；发布包不再预置可变用户配置或空数据树。
- `README.md`、`docs/architecture.md`、相关运行指南和上述主规格在实施完成后更新。本提案只创建规划产物，保留其他进行中的 change。
