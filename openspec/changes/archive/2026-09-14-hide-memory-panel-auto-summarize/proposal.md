## Why

会话右侧长期记忆面板暴露了策略、候选审批和手动维护操作，目的不清晰且占用聊天空间。用户希望屏蔽该界面，让长期记忆默认在后台自动总结。

## What Changes

- 隐藏整个会话长期记忆面板，包括策略选择、待确认数量、手动添加、候选列表及操作，并回收布局空间。
- 保留现有默认 smart 后台总结：新会话及未设置策略的旧会话自动提炼，无需打开面板。
- 取消自动提炼的人工审批队列；合格记忆自动生效，凭据、敏感推断、低可信和一次性内容丢弃。旧 confirm_all 兼容为自动筛选，显式 off 保留。
- 历史 pending 在后台重新评估：符合长期价值和可信度要求的激活，其余删除；技术失败保留原记录并重试。
- 用户明确质疑记忆时，提示在会话中澄清；明确后更正或停用对应记忆，指代不明先追问，持久化成功才告知完成。保留管理 API，不增加新的管理页面。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `long-term-memory`：取消会话页记忆管理展示要求，明确后台默认总结与 API 管理边界。

## Impact

涉及 desktop-ui/chat.js 的渲染、刷新和事件绑定、相关布局样式与 Node 测试；修改 MemoryExtractionService 的自动筛选、历史重评及聊天记忆更正链路，补充迁移、失败隔离和澄清回归测试。同步长期记忆主规格及必要用户文档，无新依赖或数据格式变更。
