## Why

当前 Agent 页面上方的建议卡片和右侧未来任务占用主要展示空间，分散了活动回顾的注意力。将页面命名为“看板”并聚焦时间轴，使用户能够直接查看各时段活动。

## What Changes

- 将中文导航 Agent 改为“看板”，英文对应 Dashboard。
- 看板正文只显示时间轴，采用占满可用宽度的单栏布局。
- 移除上方行为建议卡片及其加载、空状态，移除右侧未来任务及其占位和侧栏空间。
- 保留时间轴现有时段、详情展开、继续追问、快照展示与刷新行为。
- 本次为展示行为修改；保留后端建议生成、摘要响应字段、任务接口和会话任务能力，不新增业务能力。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-summary`：定义看板名称、仅时间轴的单栏正文，以及去除建议区域后的快照和刷新展示契约。
- `behavior-advice`：取消桌面看板必须展示建议的要求，保留后端建议模型、生成、兼容和隐私契约。

## Impact

- 桌面 UI 的 `index.html`、`styles.css`、`agent.js`、语言资源，以及 DOM 初始化、刷新和任务事件绑定路径。
- 相关 Node UI 测试与用户文档；实施完成后同步相关主规格。
- 不改变 API 路径或响应结构，不新增依赖，不删除任务数据。会话继续追问与任务上下文需要回归验证。
