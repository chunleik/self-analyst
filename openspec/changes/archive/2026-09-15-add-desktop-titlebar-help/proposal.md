## Why

桌面窗口标题栏和主导航重复展示 SelfAnalyst，挤占导航空间；使用指南、反馈和关于也缺少主窗口内的统一入口。将帮助放入应用名称右侧的标题栏，并移除桌面导航中的重复品牌，可让应用信息与功能导航的层次更清楚。

## What Changes

- 新增桌面自定义标题栏：保留应用图标和名称，在名称右侧提供「帮助」下拉菜单，右端提供窗口控制。
- 桌面版移除导航栏中的重复 SelfAnalyst，让看板、会话从左侧页边距开始；保持状态和设置入口以及正文布局。
- 新增使用指南、反馈问题、关于 SelfAnalyst 三个帮助入口，支持中英文和键盘操作。
- Web 版保留导航品牌，在导航右侧提供帮助入口，不显示桌面窗口控制。
- 标题栏改造必须保持窗口拖动、最大化与恢复、缩放、贴靠和关闭到托盘等既有体验。
- 本变更新增并调整用户可见行为，不是历史规格迁移；不增加自动更新、问题自动提交或诊断上传功能。

## Capabilities

### New Capabilities

- `desktop-help`: 桌面及 Web 帮助菜单、品牌呈现、外部指南与反馈入口、关于信息及中英文和无障碍交互。

### Modified Capabilities

- `desktop-shell`: 增加自定义标题栏及其窗口交互契约，保持原有窗口尺寸、启动、认证和托盘生命周期。

## Impact

- 桌面 UI 的 index.html、styles.css、初始化逻辑、中英文资源及 Node 测试。
- Tauri 主窗口创建、窗口权限、帮助操作桥接和关于信息复用；可能需要 Windows 原生命中测试来保持贴靠体验，具体实现先验证。
- Web 版与桌面版共享页面，需要可靠的运行环境识别及不同入口布局。
- 更新中英文 README 和窗口验收记录，实施后同步 desktop-help、desktop-shell 主规格。
- 不修改采集、会话、时间轴数据和持久化格式；不修改现有其他 change。
