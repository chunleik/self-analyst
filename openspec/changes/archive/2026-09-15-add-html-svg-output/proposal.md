## Why

会话成果目前支持七种文档格式，无法交付可离线交互的页面或可独立使用的矢量图。增加 HTML 和 SVG，使用户可以下载后在浏览器打开交互报告，或将矢量图用于后续编辑与分享。

## What Changes

- 新增单文件 HTML 输出，内嵌 CSS、JavaScript、数据及 SVG，支持离线筛选、计算和图表交互。
- 新增独立 `.svg` 输出，保留矢量结构，采用不含脚本的自包含图形。
- 扩展受管生成源以保存页面或矢量图源码，支持基于旧成果生成新版本。
- 修改被动内容约束：HTML 可包含交互脚本，但生成、校验和聊天展示阶段不执行；独立 SVG 保持被动内容。
- 两种格式沿用文件卡片、另存为或下载、历史恢复和不可变版本；不增加应用内预览，不自动打开文件。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `agent-document-generation`：扩展格式、生成源和内容边界，定义交互 HTML 与独立 SVG 的交付要求。

## Impact

- 后端文档格式、请求解析、渲染及格式校验、生成源读取、Agent 工具描述。
- 桌面下载及原生另存为的格式兼容检查；复用既有接口和会话关联。
- 文档与接口回归测试、离线浏览器验收，以及中英文 README 的能力说明。
- 无须改变数据库归属模型或扩大采集范围；解析依赖是否可复用在实施前核对。
