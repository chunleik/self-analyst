## Context

动机见 proposal.md。当前 `renderConfigTab` 顺序输出路径、测试按钮、语言选择、保存栏、运行状态和 textarea；弹窗正文整体滚动，textarea 最小高度 420px。配置弹窗还复用模型设置及文件设置的部分样式；运行状态轮询会替换自身 DOM。

## Goals / Non-Goals

**Goals:** 明确原文编辑的视觉优先级，控制滚动边界，在不改变状态与请求协议的前提下重排信息。

**Non-Goals:** 不引入编辑器库，不调整后端保存或连接测试协议，不改造文件采集表单，不增加自动保存。预览中的演示状态、运行模式切换和虚构值不进入产品。

## Decisions

0. 完整预览作为视觉参考，配置弹窗采用三个页签：模型设置、高级配置、运行数据。保留产品既有关闭、焦点返回、语言及真实 API。运行数据不再附在所有页面底部，进入时才查询；离开时失效异步响应。模型设置按预览分组和固定底栏，新输入密钥可显隐，已有密钥不回显。数据占用卡片及合计由后端的四个字节统计计算，只有迁移完成且有备份时允许确认清理；非原生环境说明目录打开不可用。
1. 高级配置使用限定作用域的纵向工作区：文件头、工具区、可收缩内容区、底部操作区。中间内容区容纳主编辑器与编辑器之后的运行信息区；保存栏处于该滚动区之外。相比仅缩减间距，这能确保辅助信息增长时操作入口仍可达。
2. 保持单列结构，不引入侧栏。弹窗宽度有限，侧栏会进一步压缩 TOML 编辑宽度。连接测试作为一组，语言控件作为另一组，窄屏自动换行。
3. 移除高级配置对固定 420px 最小高度的依赖，使用受视口约束的 flex/grid 尺寸和 `min-height: 0`。正文可滚动，原文长行只在 textarea 内横向滚动；底部操作区允许状态和按钮换行，长错误可在受限区域内完整阅读。
4. 保留现有交互元素 ID、委托事件和状态函数。为 textarea 增加可访问名称，文案使用现有国际化机制。运行信息保持独立更新，轮询不重建 textarea、不改变输入焦点，并保留来源明细展开状态。
5. 样式限定在高级配置视图容器及必要的活动视图标识内；共享 `.config-modal`、`.config-action-bar` 不作无差别覆盖。仅用 CSS 重排顺序会使键盘阅读顺序混乱，因此同步调整 DOM 顺序。
6. 三个页签使用同一配置弹窗作用域的绿色强调色、浅色面板、间距和卡片层级，保留既有全局主题。模型及原文保存栏置于各自滚动区之外，运行数据无无效保存按钮。模型测试与原文连接检查保留各自真实语义，候选列表来自后端。刷新或失败不能将未知容量伪造为零，清理失败保留当前数据及可重试入口。

## Risks / Trade-offs

- [共享弹窗样式回归] → 同时验证模型设置和文件采集设置，限定选择器作用域。
- [低高度窗口内容挤压] → 以 800×600、390×700 和 1280×800 视口检查编辑、长提示、工具换行和操作栏；限制辅助内容高度而非挤出主要操作。
- [运行轮询或语言选择刷新丢失草稿] → 复用现有状态逻辑，验证编辑文本、光标和折叠状态不受无关刷新影响。
- [静态测试不能证明布局] → Node 测试验证交互回归，浏览器使用虚构配置验证尺寸、键盘焦点并保存截图作为视觉证据。

## Migration Plan

仅发布静态 UI 资源，无配置迁移。回滚恢复对应 UI 资源即可；主规格同步和 change 归档在实现验证后执行。
