## Why

高级配置界面将文件路径、连接测试、语言选择、保存操作和运行状态纵向堆在原文编辑器之前，主次不清；编辑器的固定最小高度又增加小窗口中的滚动负担。需要围绕“查看文件、编辑、保存、核对结果”重排布局。

## What Changes

- 按已确认的完整 HTML 预览实现模型设置、高级配置、运行数据三个页签；默认模型设置，按所选页签加载数据，保留跨页签草稿确认。
- 模型设置按连接设置、模型与生成、测试及运行状态分组，增加新输入密钥显隐、可点选模型候选及持续可见保存栏。
- 运行数据成为独立只读页签，展示真实目录、运行模式、四类容量及容量合计；提供刷新、原生目录打开、迁移备份确认清理和失败重试。
- 修改高级配置的布局：顶部文件信息与辅助工具，中部原文编辑区和独立运行信息区，底部持续可见的保存操作栏。
- 连接测试和语言选择分组呈现；保存结果与草稿状态靠近保存操作。
- 运行状态展示简明摘要，来源明细按需展开；异常、待重启和旧任务使用旧版本等重要提示保持可见。
- 适配窄窗口、低高度窗口、长路径和长错误文本，补充编辑器可访问名称与键盘操作验证。
- 保留默认模型设置入口、原文保存语义、脏状态确认、语言草稿编辑和连接测试行为。这是界面行为改进，不是文档基线迁移。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `user-configuration`: 补充三个配置页签的信息分区、持续可见操作栏、运行数据展示和响应式布局契约；继续遵循 llm-settings 与 desktop-shell 现有接口及安全语义。

## Impact

- 涉及 `self-analyst-app/src/main/resources/desktop-ui/` 下 `config.js`、`ui.js`、`llm-settings.js`、`runtime-storage.js`、样式、`index.html` 和中英文语言资源。
- 保留 `docs/mockups/config-layout-reorg.html` 作为设计参考，实际产品不包含预览状态选择器、虚构数据和模拟保存逻辑。更新中英文 README 中的配置入口说明。
- 检查共享配置弹窗及 `llm-settings.css` 的样式边界，避免影响模型设置和文件采集设置。
- 运行桌面 UI Node 测试并进行浏览器布局验证；无后端 API、配置格式或新增依赖变化。
