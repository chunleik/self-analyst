## Context

主 Agent 在构建运行时填充系统提示词的 `current_time`。现有动态长期记忆中间件已在每轮生成系统提示词时运行，适合在同一位置补充本轮时间。

## Goals / Non-Goals

**Goals:** 同一运行时每轮提供新时间，保持既有本地化格式及系统提示词其他内容。

**Non-Goals:** 修改事件时间戳或桌面时钟。

## Decisions

系统提示词构建时保留专用时间占位符，在每轮系统提示词中间件执行时用该轮的本地时间替换。时间格式由现有提示词装配器统一处理，测试注入可控时间源。这样避免每轮重建 Agent，也避免解析或替换任意自然语言时间字符串。备选方案是每轮重建完整系统提示词，但会覆盖其他中间件可能添加的内容。

## Risks / Trade-offs

- 占位符如果在模型请求前未替换，会暴露内部标记 → 在中间件测试中断言标记消失，并以 Agent 已有的系统提示词链路集成测试验证。
