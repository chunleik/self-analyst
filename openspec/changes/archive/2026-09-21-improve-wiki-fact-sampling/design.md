## Context

现状及动机见 proposal.md。ActivityStatistics.activeEvents 已提供裁剪、去重、扣除 AFK 后的互不重叠区间，但其事件 ID 为合成值，不能当作持久来源引用。WikiFacts 还有被测试和其他调用方使用的构造器，需要保留兼容入口。

## Goals / Non-Goals

**Goals:** 在单次模型调用内增加事实的时间、应用、来源信息及采样公平性，保持完整指标不变。

**Non-Goals:** 不做树形生成、任务级模型证据校验、缓存、数据库迁移或历史自动重算；不引入文件事实、正文或额外模型依赖。

## Decisions

- 独立采样器生成只读标题事实。窗口区间来自共享统计，来源 ID 从同应用/标题的相交原始事件恢复；引用带来源种类，避免窗口与内容 ID 混淆。上下文按应用和系统标题关联有效窗口交集；无交集时保留观察区间并使用 null 活动秒数，避免把观察推断为活跃。标题、应用字段使用显式白名单。
- 按完整标题身份归组，再对展示标题做 Unicode 安全长度限制（最多 160 code point）。每组保留总区间数、总有效秒数和至多四个均匀分布的代表区间，每区间至多四个来源 ID；明确省略数。相邻同类区间可合并，分离区间不得连接。
- 将统计周期等分为四个时间层，各层轮流选取候选，层内优先尚未展示的应用及较长活动。窗口/上下文各分配一半预算，剩余额度再用于未选样本。最终按时间和稳定身份排序，JSON 字符数包含结构化开销，拒绝放不下的候选而不提前终止。
- WikiFacts 新增结构化样本结果，旧字符串 accessor 保留为兼容投影；生产提示词只使用结构化结果，避免重复消耗输入。旧构造器和高层级输入继续走原有路径。
- 更新事实构建与提示词版本，不修改统计/日历版本，既有 SUMMARIZED 不自动重算。采样元数据随 metrics.extra 保存，事实仅作为有界模型输入。

## Risks / Trade-offs

- 标题无法证明任务完成 → 提示词明确区分活动证据与成果，不把观察时长加到全日指标。
- 结构字段占用预算 → 采用有界代表区间与引用，极小预算明确报告省略；本期不承诺覆盖所有活动。
- 同一上下文与窗口是重复视角 → 只使用本地全量指标作为总量，不求和上下文样本。
- 长标题共享前缀 → 用完整身份归组后再截短展示，防止不同原始标题被错误合并。

## Migration Plan

无数据库 schema 变更。保持旧 WikiFacts 构造器可用，版本号只标识新生成结果；回退代码不修改或删除已有事件和摘要。
