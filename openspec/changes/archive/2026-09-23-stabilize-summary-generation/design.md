## Context

见 proposal.md。继承上轮已实现但尚未提交的代码。实际三日生成使用过临时HTTP脚本，误用了聊天温度0.7；正式plain已有0.2且禁止maxTokens，本轮不新增摘要温度配置或恢复输出上限。

## Goals / Non-Goals

**Goals:** 按三阶段顺序降低可避免拒绝、约束整周期成本并保持重启恢复，再改善真实规模任务聚合。

**Non-Goals:** 不承诺关键词或引用能够证明所有自然语言事实；不扩大采集范围，不自动重算历史，不承诺服务端账单绝对上限，不改全局所有Agent并发预算架构。

## Decisions

1. 新模型输出只包含任务语义、claimType/confidence和事实/主题成员引用；apps/evidence均由本地源目录派生。兼容旧模型多余字段不作为事实来源，不把应用别名或安装器漏列变成整日失败。未知ID、必需结构、长度及强度边界继续严格验证。修复带/含某动作字样的窗口标题等明确元描述，作用范围止于独立断言，保留反例。
2. 独立 WikiGenerationStore 使用 memoryDir/wiki-generation.db，专用SQLite短事务，BEGIN IMMEDIATE做准入；不和WikiStore共享未隔离的长连接事务。运行数据格式准入增加只读检查。预算键由level/start/end/timezone组成，终身累计，输入/model/版本及次日均不重置；默认12次、256000 token准入。单树maxCalls=6仍控制计划。用户调高额度并重启后恢复暂停条目。
3. 请求前持久化一次call预留（估计完整输入token＋4096输出余量），发出后错误/取消/未知结果保守扣额；可获usage时幂等结算真实值。正式plain关闭SDK隐式重试，确保一次预留最多一次HTTP尝试，失败只由账本约束的外层重试。普通模型不发送输出上限，因此真实输出可能超过预留，完整记录并阻止下一请求。Session提供详细结果/安全计量信息，兼容现有字符串接口；全局UsageMeter继续按执行日记录，周期账本不冒充全局原子计量。
4. 检查点key包括规范化输入、稳定模型指纹（endpoint/model/plain温度/system prompt/语言，不包含明文凭据或进程revision）、prompt/事实/统计/日历/管线版本和计划参数。叶、归并与FINAL结果校验后持久化，发布失败重试FINAL无需模型。只存规范化派生结果及引用目录，不存完整prompt或原始响应。恢复重验输入与结果；未知/损坏版本明确失败。完成检查点有界清理，未完成检查点保留用于恢复；账本计数不随检查点回收归零。
5. 失败按配置/全局预算、周期预算、网络超时、质量拒绝、输入不可行与本地发布失败分类。沿用Wiki四状态兼容，预算暂停以结构化generation进度+稳定错误显示，排除到期队列以免饿死其他周期；启动时仅在当前额度允许时恢复预算暂停项。停止先拒绝新任务、取消/等待请求结算和检查点事务，再flush用量和关闭数据库。
6. 第三阶段增加全局标题候选归组及TopicCard协议，分DIRECT/LEAF/MERGE/FINAL阶段。词法锚点与语料频率只帮助组织相近标题，不声明语义真值，也不硬编码用户业务词或增加embedding调用。生成计划先分配叶与归并额度；预算不足从全部候选分配代表而不是按块下标抽取。叶提供主题成员与代表引用，所有输入有归属或未归类状态；根以卡片为单位合并跨应用主题，保留成员链与本地派生字段，不按原事实fit后连带丢卡片。展示证据少量不等于其余成员丢失，指标分开报告。
7. 阶段1回归通过后进入阶段2，再进入阶段3。500/750/1000事实的固定种子集包含12–18测试侧主题、跨3应用/时间层、同层短任务、通用词干扰及正文诱饵。离线证明结构传递、计划确定性和预算；真实语义用独立人工审阅，不用引用通过率自证。复验正式plain参数，不增加临时按应用拆分限制。

## Risks / Trade-offs

正式plain失败分类读取SDK提供的类型化HTTP状态，并有界、防环检查异常链；不从响应正文中的数字猜测状态。402/422等不可直接重试的配置/准入问题归配置暂停，429/5xx等保持传输错误分类，未知错误不回显异常正文。

- 持久检查点含私有标题派生信息 → 留在已有本地数据根，白名单、有界结果和清理机制，无日志泄漏。
- 模型返回比预留更长 → 真实结算且停止后续；不暗示服务端token硬上限。
- 词法误归组 → 不合并/删除原事实，模型可拆分卡片，保留跨层来源和未归类账本。
- 额度永久耗尽 → 显式暂停且可调高额度恢复；不通过换模型/改输入自动获得新预算。
- 跨库发布失败 → FINAL先持久化，再幂等提交Wiki；恢复不依赖重新请求模型。

## Migration Plan

保留Wiki v4与旧任务读取兼容，新建独立派生库并加入运行数据准入检查。已有摘要不重算；新周期用新prompt/管线版本。分阶段测试、完整Maven/Node、评测与文档/主规格同步完成后归档。
