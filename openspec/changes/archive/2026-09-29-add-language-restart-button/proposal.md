## Why

设置页面保存语言后只有文字提示，用户还需手动退出并重新打开应用。提供就近的一键重启操作，让保存后的语言配置方便地统一应用到页面、原生壳和后端提示词。

## What Changes

- 新增行为：受管桌面在已保存语言仍需重启时，在高级配置底部提供“立即重启”按钮，用户点击后自动完成整个应用的重启。
- 保留既有保存语义：选择语言先修改草稿，成功保存后才提供重启操作；不在选择或保存时擅自重启。
- 按当前待重启状态更新按钮，重新打开设置仍可操作；存在未保存编辑时禁用重启并提示先保存或放弃。
- 重启处理中禁止重复提交，失败提供本地化提示；独立浏览器模式继续说明手动重启后端并刷新页面。
- 延续现有单实例、后端退出、数据目录及启动握手规则，不增加公开 HTTP 重启接口。

## Capabilities

### New Capabilities

无新增独立能力。

### Modified Capabilities

- `internationalization`：补充保存语言后的重启按钮及其状态、双语反馈和浏览器退化行为。
- `desktop-shell`：补充由设置页触发的受管应用完整重启及生命周期保证。

## Impact

涉及桌面 UI 配置保存与状态渲染、消息目录、Tauri 原生命令及退出/重新启动流程、Node/Rust 回归测试和用户文档。无配置格式变更，不引入后端热切换语言，不改变历史内容。
