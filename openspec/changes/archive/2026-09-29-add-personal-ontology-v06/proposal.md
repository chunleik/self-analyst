## Why

SelfAnalyst 的时间摘要、项目记忆与目标缺少共同的实体身份，跨日期和应用的同一项目难以稳定检索、解释和纠错。0.6 将个人活动本体作为主要功能，让用户能围绕项目、主题和目标查看带证据的活动关系，保留未知与推断边界。

## What Changes

- 新增个人本体：项目、活动片段、应用、主题、目标、模式及改进记录的稳定实体、类型化关系与带来源的断言。
- 从当前有效 Wiki 和 active 记忆生成本地语义投影，支持项目别名、确定性关联、歧义保留、跨日期查询与证据解释。
- 提供实体创建/编辑/删除、别名、合并、关系确认/否定/改正；用户决策在重建与重启后保留。
- 提供桌面“知识”入口、实体检索、关系详情、活动时间线、证据与覆盖说明，以及 Agent 有界查询工具。
- 将目标、已知模式与改进记录接入同一只读来源投影，保持 memory.json 记忆权威与停用/删除语义。
- 提供原子重建、来源失效处理、格式版本准入、恢复与备份说明；保留标题采集和文件元数据边界。
- 同步 0.6.0 版本标识、中英文 README、架构和用户指南，完成回归、全量验证、功能分支提交/push 与 PR 必需检查。

## Capabilities

### New Capabilities
- `personal-ontology`: 实体、关系、证据、用户纠错、本地投影、生命周期、桌面与 Agent 查询。

### Modified Capabilities
- 无。新入口和工具的行为由 personal-ontology 定义，已有事件、Wiki 和记忆的权威及契约保持兼容。

## Impact

新增 self-analyst-ontology Maven 模块；应用生命周期、Agent 工具注册、桌面 API 与多语言 UI 接入；Wiki/Memory 只读适配；版本与文档更新。使用现有 SQLite/Jackson 技术，不引入图数据库服务、普通文件内容读取或额外模型调用。用户写入与可重建投影分离，现有数据库不破坏性迁移。
