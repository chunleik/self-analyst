## Context

动机见 proposal.md。OntologyStore 的 projection 不含手工状态，只有 OntologyService.graph() 包含最终匹配和纠错。配置现有 TOML 机制不提供密码保险库，故仅持久化环境变量名称。

## Goals / Non-Goals

**Goals:** 导出同一锁下刷新的最终不可变快照；所有发送只由桌面手工确认入口发起；默认不连接。

**Non-Goals:** 全量事件/Wiki 迁移、后台调度、图查询替代、本体恢复工具、向量迁移、实际用户服务部署。

## Decisions

- 使用官方 Java driver 的隔离打包版本（neo4j-java-driver-all 5.28.15），避免影响应用既有 Netty/Reactor；使用参数化固定 Cypher，单写事务内以命名空间元节点串行化更新。固定应用标签和关系类型隔离其他数据，不拼接用户内容为 Cypher。
- Entity 保持稳定 id，Assertion 使用现有关系 key；属性保留来源、时间、性质、候选、证据 JSON 与属性 JSON。合并旧 id 存入目标 mergedIds，拒绝决定通过最终关系移除体现，不发送失效端点的历史正文。
- 单个不可变快照包含 coverage；本地快照大小/序列化字节预算不通过时不连接、不清理。来源本身的有界覆盖如实保留。
- 按命名空间标记本次 generation 后清理旧自有关系和节点。若过期自有节点仍被外部关系引用，移除应用内容并保留仅标识的 tombstone，以避免删除外部关系。
- 支持 bolt 明文仅环回主机（不允许明文 neo4j 路由地址，避免路由到远端），远端仅 +s TLS；拒绝 +ssc、嵌入凭据、查询、片段及多余路径。设置连接/获取/事务超时及客户端总截止时间；顺序等待异步操作，无延迟发送批次或提交的后台延续。超时后有界关闭驱动，关闭未完成时保持单飞门禁，防止反复创建资源；提交阶段超时可能结果不明，不能声称远端未写入。
- 密码只从配置指定进程环境变量读取，状态仅检查是否缺失，配置只保存名称。服务异常只返回分类代码，不把驱动异常、URI 密码或数据写入日志。
- 设置保存即时供下次手工操作读取；确认绑定公开配置指纹，防止用户确认旧目标后配置改变而发送到新目标。

## Risks / Trade-offs

- [远端旧数据仅在下次同步清理] → 文档明示关闭功能不删除远端；敏感数据仍由用户管理目标。
- [不同客户端误用同一命名空间] → 配置必须显式提供命名空间，UI 确认并文档提示独占使用。
- [大快照写入耗时] → 有界批次、单事务、有限超时、UI 状态和防重复请求。
- [图谱可能含私密标题及用户描述] → 每次操作告知数据范围，默认关闭且没有 Agent 同步工具。

## Migration Plan

无本地存储迁移；新增配置默认关闭。回退只需禁用同步，原应用查询仍使用本地存储。远端投影不会自动删除，用户自行保留或清理。
