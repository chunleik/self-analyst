# Proposal

## Why

SelfAnalyst 已有单一联网搜索 MCP，但缺少统一的连接配置、工具授权和状态管理。用户需要在应用内部查询 QQ 邮箱与普通 163 邮箱，因此应先建立可控的外部 MCP 接入和内置只读邮箱能力，避免为仅供自身使用的邮箱功能增加独立服务或放宽现有采集隐私边界。

## What Changes

- 新增受认证的“连接与工具”设置入口，统一展示外部 MCP 和内置邮箱，但明确区分真实 MCP 传输与进程内连接器。
- 新增版本化、独立于现有拍平 TOML 的连接配置；外部 MCP 第一阶段仅支持 Streamable HTTP，以及匿名或目标绑定的 Bearer 认证。保存、连接测试、工具授权和启用是独立操作。
- 将现有 Parallel Search 的连接和关闭职责纳入同一管理层，保留 `websearch.*` 兼容配置与重启语义，不自动迁移密钥、不重复注册、不让两个来源共同修改同一连接。
- **BREAKING（安全收紧）**：旧搜索入口同样需要工具批准和逐次调用确认，不再凭“搜索”名称豁免任意远端工具；明文、私网及环回 MCP 目标不在首期支持范围，原配置保留但不发出请求。
- 新增 QQ 与普通 163 的内置 IMAPS 连接器，使用完整邮箱地址及客户端授权码；163 发送真实客户端 IMAP ID。仅查询账户、文件夹、邮件列表及按需读取正文，不实现 SMTP、修改邮件或附件下载。
- 新增独立凭据引用、受控工具调用、账户与文件夹范围校验、可取消的有界网络操作及分类错误。永久保存凭据只使用受支持的系统凭据库；不可用时提供明确的仅会话模式，不降级到普通配置明文保存。
- 明确邮箱内容可能发送给当前模型，并可能随会话、AgentState 与压缩摘要保存；不宣称正文零落盘。不建立邮件全文库，不自动进入 Wiki、长期记忆、本体或 embedding，不改变标题/文件元数据采集边界。
- 对外部 MCP 的未批准工具及变更后的描述/schema 默认不执行；每次调用均受后端策略检查和逐次确认。邮箱来源会话还阻止 embedding 查询及未经逐次确认的原生写入，不能以远端只读注解、模型参数或 Agent 配置工具代替用户授权。
- 本次为新增能力与既有工具生命周期行为修改，不是历史规格迁移。规划完成后已取得用户实施授权；本地实施验证已经完成，随后用户明确授权 PR、合并及发版；仅通过远端质量门禁后推进，不本地打包。

## Capabilities

### New Capabilities

- `mcp-integrations`: 外部 MCP 连接配置、生命周期、工具目录与授权、凭据隔离、诊断及桌面设置。
- `mail-integration`: 仅供 SelfAnalyst 使用的 QQ/163 账户、只读 IMAP 查询、内容处理、用户授权及保留边界。

### Modified Capabilities

- `web-search`: 保留单一旧配置入口，统一客户端管理并明确其与新增通用 MCP 配置的边界。
- `user-configuration`: 独立连接配置文件及凭据存储与原有 TOML 的职责划分，受认证入口及生效状态。
- `agent-runtime`: 统一注册受控外部/内置工具，保持串行执行、每轮工具快照、撤权检查及失败隔离。
- `long-term-memory`: 邮箱来源会话的自动提炼排除，避免现有 smart 默认流程把邮件内容再次持久化为长期记忆。

## Impact

- `self-analyst-app` 中新增 MCP、邮箱、凭据及权限服务，修改 `SelfAnalystAgent`、`DesktopServer` 与桌面控制器；优先保持在现有 app 模块，不新增外部邮箱服务进程或监听端口。
- 设置窗口、工具执行状态与中英文资源；沿用已有草稿、请求代次、取消及受管桌面认证模式。
- 引入与 Java 21 兼容的 Jakarta Mail/Eclipse Angus 实现；采用现有 AgentScope/MCP SDK，不自行实现 MCP 编解码或 IMAP 协议。
- 新增连接元数据及系统凭据引用的备份/断开语义；现有 ChatGPT 与 API Key 凭据不自动迁移或改写。
- Java、Node、必要的原生凭据/Windows 检查；全部自动化使用合成账户与协议夹具，不使用真实用户邮箱或凭据。
- 实施同步架构、连接指南、PRIVACY、双语 README 与已实现主规格；功能通过 PR 与最新提交的必需检查交付；未发布前不宣称已经上线。
- 本期不包含 stdio/旧 SSE、自定义 IMAP 主机、Gmail/Outlook OAuth、企业/VIP 邮箱、公共邮箱 MCP Server、后台同步、发信或邮箱写入。
