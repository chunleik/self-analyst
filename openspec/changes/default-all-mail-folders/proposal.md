## Why

beta.18 的目录选择器过于繁琐。用户在 2026-11-15 明确要求删除整个文件夹范围配置区域，固定读取全部文件夹，并明确无需旧版兼容。本修订延续现有 change；此前 beta.18 实施证据保留在 verification.md，不代表本修订已发布。

## What Changes

- 删除范围下拉、解释、搜索、加载/刷新、全选/清空及目录复选列表，以简短全部范围说明代替。
- 新建和新 UI 保存/启用固定 `all`，覆盖未来新增目录。不迁移旧指定范围，明确拒绝不支持的配置，不伪装为全部。
- 删除前端目录发现和取消状态机；设置页打开、保存、启用不自动调用目录发现。
- 保留独立正文许可、模型目标与留存告知、加密保存启用确认及断开/删除。
- 保留底层按需读取、既有独立配置能力和受认证目录发现接口，不改变外部 MCP。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `user-configuration`: 固定全部范围，去除目录选择 UI 与自动发现。
- `mail-integration`: 明确新配置页不调用管理端目录发现，后台按需读取不变。

## Impact

修改桌面前端、Node/合成浏览器回归、用户文档和两份主规格；不改 Java、依赖或版本，不迁移真实配置。本轮不提交、推送或发版。
