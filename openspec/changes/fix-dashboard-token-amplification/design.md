## Context

动机见 proposal.md。现有摘要组装会同步增强 current/today 与建议；事实指纹失效能在每次轮询时绕过文案缓存。plain 调用失败时仍按输出预留记账，计量文件缺少来源。模型租约在 HTTP 请求返回时关闭，因此不能将该租约直接交给后台使用。

## Goals / Non-Goals

**Goals:** 将本地事实读取与模型生成生命周期分离；对实际模型批次建立独立于事实变化的持久准入；兼容旧快照与用量文件。

**Non-Goals:** 不修改供应商计费、不回填猜测历史真实消耗、不关闭 Wiki、不限制模型服务端输出。

## Decisions

- 摘要组装器持有单线程后台执行器与独立准入状态。HTTP 组装同步读取本地事实、已有模型文案和 Wiki，仅在需要且准入允许时提交一个批次。并发组装串行化短状态操作；模型执行期间不持有组装锁。
- 正常批次至少间隔 5 分钟；失败按 5/10/20/40/60 分钟指数退避。准入时先将下一准入时间写入摘要快照，重启保留门槛。只保持一个 in-flight 批次，不保存排队请求。语言及统计日变化使旧文案降级，但不绕过准入。
- 后台在真正执行时获取自己的模型租约，并在完成/失败时关闭。每次增强允许 60 秒；首个失败后跳过剩余模型调用。模型响应与输入事实引用配对保存；过期统计日/语言的批次不能覆盖新范围快照。
- 成功文案使用生成所依据事实的指纹；轮询只更新本地统计，不推进文案生成时间。对兼容的缓存保留任务引用及标题投影，避免引用错配。
- 来源计量为累计附加字段；原三项计数及 totalTokens 保持预算意义。record 的默认来源为真实，Agent/compaction 的无 usage 回退显式标为估算，plain 未完成无 usage 标为预留。旧累计差额为未分类，不改写生产历史文件。
- 用量明细放入已有状态/设置可见区域，沿用双语消息目录。前端摘要共用一个进行中 Promise，页面隐藏不发请求，恢复可见合并刷新。

## Risks / Trade-offs

全量验证中的历史迁移夹具按接收时间的 UTC 月份确定原始分区，改用写入回执派生路径，避免日历跨月使固定月份路径失效；不修改事件存储实现或迁移契约。

安装包构建中的可选 titlebar-review target 已由 required-features 隔离，但 Tauri CLI 的 src/bin 自动扫描会重新将其纳入。将验收源码移到 src/review，并保留显式 target 与 feature gate，使正式包只包含实际启用的二进制，验收工具仍可按原命令编译。

- 文案可能比活动晚数分钟 → 本地统计仍实时更新，展示文案来源和生成时间；历史 Wiki 不受准入影响。
- 模型故障时仍有不确定成本 → 保留保守预算且单列预留；退避避免持续重复消费。
- 后台完成时事实已经变化 → 保留其原始引用，不将旧生成指纹冒充新事实；后续准入可生成新主题。
- 重启及关闭与后台并发 → 持久准入、防止关闭后提交；关闭执行器并释放模型租约后再释放模型/存储。

## Migration Plan

新字段可选读取，旧快照和计量文件保持可用。新增测试通过后同步主规格并归档 change。生成可安装构建并按仓库功能分支、PR 与必需检查流程交付；生产历史用量不做回写。回滚旧程序仍能读取原有字段。
