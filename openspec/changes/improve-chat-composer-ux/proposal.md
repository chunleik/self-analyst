# Proposal

## Why

会话页的增强输入框视觉上只有一行，图片选择器和常驻限制说明又独立占用一整行，长消息和图文输入体验割裂。优化为统一的多行输入区，让文本、附件、发送状态和反馈处于同一操作区域，同时保留现有会话、流式响应和失败重试语义。

## What Changes

- **修改体验**：增强消息面和原生 fallback 均使用默认约 2～3 行、随内容增高且达到上限后内部滚动的输入区；发送成功清空后恢复初始高度。
- **修改布局**：文本区、图片缩略图、添加按钮和发送/停止操作整合在一个输入容器内，固定于主会话区域底部，消息独立滚动，不再常驻展示原生文件选择控件和整行图片限制。
- **新增行为**：支持向输入容器拖入 PNG/JPEG 图片，沿用既有图片校验、预览、移除和会话隔离；选择文件与粘贴图片是已有能力，不作为新功能重新实现。
- **统一交互**：空内容禁发，有有效图片可仅发图片；准备中防止重复提交，模型生成中可停止，错误在输入区就近显示且不只依赖颜色。停止沿用已有取消能力，不改变后端协议。
- **保留并加强验证**：Enter 发送、Shift+Enter 换行、中文输入法组合保护、失败草稿保留、切换会话隔离、键盘/焦点/ARIA、中英文与浅深色主题。
- 仅规划桌面会话页，不改后端 API、图片数量/大小限制、模型选择、会话历史或采集行为，不增加通用文件上传或 UI 框架。

## Capabilities

### New Capabilities

无，复用现有能力边界。

### Modified Capabilities

- `desktop-chat`：输入区的自适应尺寸、底部布局、一体化操作和可观察状态反馈；保留现有流、取消、重试和键盘契约。
- `chat-image-input`：将主动图片拖入纳入输入来源，统一附件操作和就地反馈，保留上传与隐私边界。

## Impact

- 前端：`self-analyst-app/src/main/resources/desktop-ui/` 中 `index.html`、`styles.css`、`chat.js`、`chat-images.js`、`deep-chat-adapter.js`、新增 `chat-composer.js`、必要的 `events.js`、`summary-repair.js` 事件及草稿绑定与 `locales/zh.json`、`locales/en.json`。
- 验证：已有会话路由、图片、增强适配器和样式 Node 测试，补充输入区行为测试；真实 Windows Tauri 验证拖放、中文输入法、窄窗口和浅深色效果。
- 用户文档：实施时同步 README 两种语言中会话图片输入说明。提案阶段不更新主规格、不归档、不修改实现。
- 不引入第三方依赖。经用户确认，在 Tauri 主窗口关闭原生拖放拦截，以便使用 DOM File 通路；不新增文件读取权限。增强与 fallback 共用外置输入区，保留流式和取消能力。
