Clear data boundaries

Local first.
Know what's recorded.

Activity and conversations are stored on your computer. Collection and optional online services have distinct settings and boundaries.

Full privacy details (Chinese) ↗
  • Titles, without persisted body text. Recognition may temporarily read accessibility information, but UIA body text and control trees are not saved.
  • File metadata only. Collect names, paths, sizes, and timestamps within explicitly configured folders, without reading ordinary file contents.
  • No screenshots, OCR, or audio collection. If recognition fails, collection falls back to system window titles.

Local-first does not mean fully offline. When enabled, LLM, embedding, and web search services receive relevant inputs. File metadata returned by tools may also enter conversations with your configured model.

Get started

Start on your own computer.

01

Choose your package

Get the Windows x64 installer from Releases, or extract and run the portable package. Both include a Java runtime. The desktop interface uses your system's WebView2 Runtime.

02

Connect your model

Open Settings → Model settings in the desktop app. Enter your endpoint, model, and API key, test the connection, and save. Enter keys only in the desktop app.

Model setup guide (Chinese) ↗
03

Make time to reflect

After some activity, ask “What have I been working on today?” File collection is off by default; enable it and choose folders if needed. Closing the window hides it to the tray. Use the tray menu to quit.
