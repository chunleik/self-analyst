本地优先。
知道记录了什么。

活动与会话数据保存在本机。采集范围和可选联网能力，分别说明、分别配置。

阅读完整隐私说明 ↗
  • 保留标题，不持久化正文。标题识别可能临时读取无障碍信息，但不保存 UIA 正文或控件树。
  • 文件采集仅限元数据。只在显式配置的目录内采集文件名、路径、大小和时间，不读取普通文件正文。
  • 不采集截图、OCR 或音频。识别失败时回退到系统窗口标题。

本地优先不代表全部离线。启用 LLM、Embedding 或联网搜索时，相关输入会发送到你配置的服务；文件元数据作为工具结果时也可能进入模型会话。

快速开始

从自己的电脑开始。

01

选择并运行分发包

在 Releases 中选择 Windows x64 安装包，或解压便携包后运行程序。分发包已包含 Java runtime；桌面界面使用系统 WebView2 Runtime。

02

连接你的模型

在桌面「设置 → 模型设置」填写服务地址、模型与 API 密钥，测试连接后保存。密钥只在桌面应用中填写。

03

开始第一次回顾

积累活动后，试着问「我今天主要在做什么？」。文件采集默认关闭，需要时启用并添加监控目录。关闭窗口会隐藏到托盘；退出请使用托盘菜单。
